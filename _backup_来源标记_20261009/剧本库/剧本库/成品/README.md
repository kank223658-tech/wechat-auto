# 成品库（定稿剧本专用）

这里是**定稿剧本**的专属文件夹：机械门全绿 + 评委放行 + 用户确认过的终稿才进来。

## 收录规则
- 每批一个子文件夹，命名：`批次_日期_主题`（如 `十五连_0915_街搭6视频`）
- 子文件夹内放：剧本 txt + `00_总任务书.md`（若有）+ `README.md`（索引/图片清单）
- 写作过程材料（草稿、范本、修改记录）留在外面，不进成品
- ⚠️ 进了成品就不要再原地大改；要改先移出去改完再回来
