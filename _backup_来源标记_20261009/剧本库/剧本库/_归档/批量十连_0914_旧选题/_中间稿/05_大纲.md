# 05_大纲 女生半夜发「睡不着」

## 一、人物与关系
- 软软的雪（主线）：失眠体质，深夜活跃矫健、白天高冷。与男主处于未确认关系的观察期，深夜信号真假待验。
- 椰椰不上班（副线）：熬夜搭子，毒舌松弛，负责把深夜氛围托住、给男主垫场。
- 粉丝-龙龙（引流）：围观型粉丝，用「磕到了」「求后续」类弹幕带节奏，向主页/合集引流。

## 二、主线 4~6 节点转折具体
1. 22:58 她发「又睡不着了」→ 男主先接情绪，不聊骚、不卑微。
2. 23:02 她发[图片]猫在腿上 → 大图开门即冲击，男主回「我也没睡 正好」。
3. 男主把「睡不着」聊成「为什么睡不着」→ 给安全感、轻拆解情绪。
4. 轻话题助眠（猫/白噪音/明天早餐）→ 到点劝睡，不恋战。
5. 次日白天她主动说「昨晚聊完好睡多了」→ 验证窗口为真、关系升温。
6. 白天恢复正常节奏，男主不黏，留白等下一夜信号。

## 三、副线安排
椰椰不上班深夜段穿插 10~14 条：吐槽失眠、晒宵夜、调侃男主「又被信号叫醒」，用搭子语气坐实男主身份、避免独白尴尬；次日白天补 1~2 条「你俩成了？」收副线，不抢主线。

## 四、画面运用 4~8 个
1. 22:58 聊天框「又睡不着了」特写。
2. 23:02 猫在腿上大图满屏，第一眼冲击。
3. 深夜居家暖光桌面/手机微光分镜。
4. 男主打字时猫元素呼应（桌面/壁纸）。
5. 劝睡时时间显示接近 00:30。
6. 次日白天阳光对话框，她「好睡多了」截图。
7. 龙龙弹幕「磕到了」浮层。

## 五、技巧点 6~8 条≤14字
1. 先接情绪不聊骚
2. 我也没睡给安全感
3. 睡不着转为什么
4. 轻话题助眠收尾
5. 到点劝睡不恋战
6. 次日白天验真伪
7. 副线托氛围不抢戏
8. 猫图开门即冲击
