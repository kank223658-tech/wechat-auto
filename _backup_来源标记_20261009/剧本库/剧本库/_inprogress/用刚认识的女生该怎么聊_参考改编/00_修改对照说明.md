## 三、第二步：内容修改（就 4 处，其余没动）

### 改动 1｜开场：直球彩虹屁 → 可歪引擎钩子（最大的一处）

**原文（底稿）**：
```
[我方发消息] 排场是给你做的
[我方发消息] 白天想当面说 太紧张没说出口
[对方发消息] 哦 那现在补上
[我方发消息] 黑白格裙 你在路灯底下最先亮
[我方发消息] 递手机那下 你手忙了一下
[我方发消息] 风把头发吹乱 你也顾不上理
```
问题：一上来三连具体夸 = 公式化彩虹屁，第一屏就把牌打完了。

**改后**：
```
[我方发消息] 白天有句话 憋到现在没敢发          ← 悬念（宾语空着）
[对方发消息] 哦 那现在补上
[我方发消息] 这句得看你脸色发                    ← 继续吊
[对方发消息] 我脸色还能吃了你 / 说
[我方发消息] 你递手机那下 手忙了一下
[我方发消息] 我到现在还在想那一下                ← 往歪处引（想什么？观众想歪）
[对方发消息] 想出什么了
[我方发消息] 想出黑白格裙 路灯底下最先亮        ← 落点拉回极日常的夸
[我方发消息] 话就到这 多一个字都算骚扰          ← 自我刹车，反推拉
```
依据：可歪引擎定调——诱惑性靠"话没说满"，不是靠漂亮话堆叠；保留底稿最好的一句夸（黑白格裙），砍掉第三句（风吹头发，凑数感）。

### 改动 2｜闺蜜质问段：加「那你呢」反将（4 行）

在"她出卖我 / 那得谢谢她"之后插入：
```
[我方发消息] 那你呢 听完汇报 笑没笑
[对方发消息] 笑了又怎样
[我方发消息] 不怎样 就是比你嘴上承认的诚实
```
她来质问，我方反手把问题抛回去——智斗感，也是机械门"全程引擎"要的张力。

### 改动 3｜粉丝线教学点：从"街搭三步"改成对题的"刚认识三步"

**原文**：一开场给见面礼 二三句内具体夸 / 三别等她问 直接给机会
**改后**：一开场别急着夸 先递个钩子让她追着问 / 二把话往歪处引一句 马上拉回正经 / 三她开始接梗了 再给有时间有地点的邀约
教学点必须和开场演示一致，观众才能"看完就会"。

### 改动 4｜结尾字幕对题 + 字幕瘦身

- 「下课 不会升温就来找我」→「下课 不会聊就来找我」
- CTA 换成规范固定文案「想要聊天秘籍的兄弟 点赞关注扣6我安排」

### 改动 5｜插话写法升级：行内第 3 段 → 拆行式 `[她插话]`（0919 新规范）

参考稿里的写法：
```
[观众字幕] 直球开场 图替我说话 | 0.5 | 好大的排场
```
一行里挤了「我方草稿 + 停留 + 她的真消息」三个信息、零角色标注——模型反复把她的台词写成我方口吻、
或让插话去回应还没发出去的草稿（她根本看不见草稿）。

本稿已全部换成拆行式：
```
[观众字幕] 直球开场 图替我说话 | 0.5
[她插话] 好大的排场
[清空输入框] -1
```
`[她插话]` 行 = **她打字发出去的真消息**（进聊天记录）；行名即角色，一行只写一个演员。
渲染结果与旧写法 100% 一致（解析器等价性已逐步骤校验），但模型理解零歧义。
规则库 74 篇参考稿已全部同步迁移。

## 六、顺手修了一个引擎 bug

给图片槽写配图注释（`# 效果＝…`）时发现：`script_translator.py` 的 `convert_inline_speaker_messages` 不跳过 `#` 注释行，带冒号的注释（`# 效果＝见面礼：金毛照`）会被当成「人名：消息」误转成 `[对方发消息]`，直接污染成片步骤。已修（`#` 行原样保留交 parse_script_text 处理），复跑门禁通过。
