# 09 大纲｜「你太好了我配不上你」怎么接

## 一、人物与关系
- **唐一一（主线）**：被前任画大饼伤过，嘴硬心虚；用「配不上」+「走高冷路线」立防御姿态，其实怕再受伤。
- **米朵朵（副线）**：甜甜闺蜜型，爱起哄，负责把一一的嘴硬戳穿、制造反差。
- **粉丝-龙龙（引流）**：代表「听不懂软拒绝」的男生群体，以观众视角提问代入。
- 关系线：我（温和拆解）↔ 一一（防御）；朵朵（旁敲）↔ 一一（嘴硬）；龙龙（投射）↔ 观众。

## 二、主线 4~6 节点转折具体
1. **钩子开场**：大图「御一下」+「走高冷路线」先入眼，我点破这是防御不是真高冷。
2. **点破话术**：「你太好了」是软拒绝话术不是夸奖，温和点破、不拆穿得难看。
3. **点破配不上**：「配不上」=怕再受伤，呼应历史「上一个人画的饼太大」，共情不贬低。
4. **小承诺兑现**：给确定性——说到做到、不画大饼，用一件小事的实际兑现证明。
5. **她试探**：一一故意冷场/反话测我言行一致，我稳接不崩。
6. **转折收尾**：她问「那你说你自己哪里不好」=开始认真考虑，留白不答满。

## 三、副线安排
- 米朵朵 10~14 条短展开，穿插主线节奏：起哄「她就是喜欢又怕」、转述一一私下破防、制造糖反差。
- 龙龙以粉丝身份在旁提问「这算拒绝吗」，强化受众代入与共情。

## 四、画面运用 4~8 个
1. 开局满屏大图「御一下」占视觉中心，先给冲击。
2. 「走高冷路线」配冷色调与表情包强切换。
3. 「上一个人画的饼太大」历史截图回放，埋呼应。
4. 小承诺兑现：日程/截图证据特写，给确定性。
5. 她试探时气泡反复删改的微动画。
6. 结尾「你自己哪里不好」定格 + 黑屏留白。

## 五、技巧点 6~8 条
1. 点破话术不拆穿
2. 不卑微不画饼
3. 共情怕受伤
4. 小承诺给确定
5. 稳接试探不崩
6. 留白引她追问
7. 闺蜜反差助推
