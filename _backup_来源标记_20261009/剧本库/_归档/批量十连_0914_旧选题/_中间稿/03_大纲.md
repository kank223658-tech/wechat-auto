# 03_大纲：女生说「我们不熟吧」怎么升温破冰

## 一、人物与关系
- **半糖柚柚（主线）**：慢热防备型女生，刚认识即划安全距离，用「不熟」立界限；非真冷漠，只是要节奏，线内可聊、越界即冷。
- **男主（代入视角）**：刚认识被划线的男生，热脸贴冷屁股但守住自尊，不卑微不硬蹭。
- **阮甜甜（副线）**：柚柚闺蜜，热心支招型，但支的全是馊主意，负责反差笑点与对照。
- **粉丝-龙龙（引流）**：评论区/直播视角，提问、催更、共鸣，把观众拉进剧情。

## 二、主线 4~6 节点转折具体
1. **开场钩子**：历史块末条女生背影大图 +「我们不熟吧」画外音，男主被明确划线。
2. **节点1-承认不熟**：男主回以承认不熟、顺势说才要聊，不硬攀、不卑微，破掉讨好感。
3. **节点2-共同锚点**：抛出她曾说「上周那个展人超多」，确认俩人都去过，建立真实连接点。
4. **节点3-先交底**：男主分享自己看展的糗事与感受，替代连珠提问，让她有接话空间。
5. **节点4-小忙试探**：请她帮挑一个展相关的小事（举手之劳），她顺手应下，互动破冰。
6. **节点5-窗口开+转折**：她主动发来第二句、反问我方问题，亲手打破「不熟」界限，升温完成。

## 三、副线安排
阮甜甜以闺蜜口吻穿插支招，短展开 10~14 条馊主意，制造笑点与反向对照：
猛烈表白 / 送名牌礼 / 早安轰炸 / 写千字小作文 / 朋友圈狂点赞 / 假装偶遇 / 土味情话连发 / 查住址送惊喜 / 雇人送花 / 秒回每一条 / 公开示爱 / 找闺蜜反向助攻 / 送猫求收留 / 深夜 emo 轰炸。
每条由男主轻驳，反向印证正确打法，不抢主线篇幅。

## 四、画面运用 4~8 个
1. 女生背影大图（开场钩子，划界限视觉）。
2. 聊天框「我们不熟吧」气泡特写。
3. 展览现场人潮照片（共同锚点画面）。
4. 男主看展糗事配图。
5. 小忙请求与应允的对话框。
6. 她主动发来的第二句气泡高亮。
7. 阮甜甜支招的弹幕/便利贴堆叠。
8. 升温后两人同展新合照（收尾）。

## 五、技巧点 6~8 条（≤14字）
1. 承认不熟不硬攀
2. 找共同经历锚点
3. 分享代替提问
4. 自己先交底
5. 小忙试探窗口
6. 她主动即开窗
7. 不卑微不等待
8. 绝不写小作文
