# 02 大纲｜第一次约女生出来的话术

## 一、人物与关系
- **桃桃乌龙**：线上聊得热络却没见过面的女生，本能有防备。21:52 发自拍求评价，是主动开窗信号，第一眼须放大图接住。
- **芋泥啵啵**：共同好友/粉丝，起哄催约型副线，负责把气氛拱热、制造外部推力，但不替男主代约。
- **粉丝-龙龙**：轻度引流位，偶尔冒泡助攻，不抢戏。
- 关系基调：男主处在「聊很久不敢开口」的低位焦虑，需用「熟」消解距离，再自然过渡邀约。

## 二、主线剧情（5 节点·转折具体）
1. **接住自拍梗**：放大自拍，夸刘海、聊发型共同话题，把关系温度从「聊得来」推到「熟」。
2. **试探性半约**：抛「那家湘菜据说排队疯了」，只陈述不邀请，观察她是否接梗，全程不施压。
3. **接梗即锁细节**：她接话 → 立刻把时间+店名说死，降低她决策成本，不给反悔空隙。
4. **转折·她递台阶**：她主动问「就我们俩？」——自己把台阶递过来，顺势确认、给安全感。
5. **收口给安心**：回「就吃个饭 不干嘛」，首次邀约锁定吃饭，不做夜场，约成收线。

## 三、副线安排
芋泥啵啵在节点 2、3 之间穿插 **10~14 条**起哄：「你再不约黄花菜凉了」「桃桃都发照片了你怂啥」，制造「全世界都在催」的外部推力。龙龙偶尔补刀助攻。副线只拱火不代约，主邀约动作始终落在男主身上，保持男主主动性。

## 四、画面运用（6 个）
1. 自拍照大图首屏铺满（21:52 发自拍触发）
2. 湘菜店门口排队实拍图（半约时抛出）
3. 刘海剪前剪后对比拼图（接梗升温用）
4. 芋泥啵啵表情包刷屏连击（副线拱火）
5. 「就我们俩？」对话框高亮特写（转折锚点）
6. 店名+定位卡片（锁细节时甩出）

## 五、技巧点（7 条·≤14 字）
1. 接住自拍先升温
2. 试探半约不施压
3. 她接梗即锁细节
4. 含糊就退一步
5. 隔天新题重启
6. 邀后给足安全感
7. 首约只约吃饭
