# 批量十连 · 共享硬规则（每稿写前必读、交稿逐条自查）

## 一、行格式
- 一行一条指令，格式 `[动作名] 参数`，多段参数用「|」分隔。
- 允许的动作全集（别的都不许用）：
  [历史会话]…[历史会话结束]、[会话] 名、[打开聊天] 名、[返回主页]、
  [我方打字] 内容、[对方发消息] 内容、[打字不发] 字幕 | 0.5 | 插话（第3段可省）、[删除文字] -1、
  [等待] 0.3、[对方后台发消息] 名 | 内容 | HH:MM、
  [发送表情] 短名、[对方表情] 短名、[发送图片] 图片=脱单教程 | 打开=否（仅粉丝会话）、
  [手机状态栏] 无新消息、[打开对方主页] 名、[进入对方朋友圈]、[点开图片] 序号=1,1、[等待] 1.2（看图后）
- 禁用：闪回聊天、我方发链接、转账、语音；历史块里已有的图，实时段绝不再发（双投）。

## 二、[打字不发] 与插话
- 格式 `[打字不发] 字幕 | 0.5`，常规一律 0.5（仅合并长字幕/大博弈窗口用 1.0~1.5）；每条后紧跟 `[删除文字] -1`。
- 字幕=给观众看的短语标签：主体 2~10 字（硬上限 14），「动作短语 + 空格 + 三五字补充」。金样：
  接住不破防 / 顺着结论走 / 她等你追 你偏不追 / 回头也慢半拍 / 别哄太满 立边界 / 暗示见面 / 学以致用
  禁止 15+ 字解释句。引流 CTA / 下课字幕可 13~20 字。
- 插话=她对没发出去的字的反应，全部收进第 3 段，多段用「；」，只能是她台词。
  唯一合法结构：`[打字不发] 字幕 | 0.5 | 反应1；反应2` → `[删除文字] -1`
  [删除文字] 之后、下一个我方动作之前，禁止任何 [对方×] 行（[对方后台发消息] 豁免）。

## 三、节奏与对白
- 对方相邻连发两条（中间无其他动作）之间必须插 [等待] 0.3；我方消息之间不加。
- [我方打字] 口语 ≤20 字；要有连发 2~3 条的段落，别写成严格一问一答。
- 复读禁令：同一句话全篇不出现第 2 次；同一句式（如「你倒是会X」「你变了」）全篇最多 3 次。
- 3D emoji 内嵌进消息文本（如「行吧[Emm]」），每个全篇只用 1 次。

## 四、历史块（10 个 [会话]，[历史会话] 开头 / [历史会话结束] 收尾）
- 按最后一条消息时间从新到旧排；同一人只一个会话；同一会话只有首末条带「| HH:MM」且间隔 ≥5 分钟，末条必带时间；同一人连发 ≤2 条；带「我：」回复的仅粉丝会话 1 个；禁「在吗/哈哈/吃了吗/晚安」空话。
- 粉丝会话必含：`[对方发链接] 聊天案例解析（必看） | 随机 | 恋爱技巧 | HH:MM`。
- 其中 1 个会话放系统消息：`某名：我通过了你的朋友验证请求，现在我们可以开始聊天了 | HH:MM`。

## 五、结构骨架（段序固定）
```
[历史会话]…[历史会话结束]
[打开聊天] 主线 → 主线A → 段尾 [对方后台发消息] 副线名 | 内容 | t1 → [返回主页]
[打开聊天] 副线名 → 副线段 → 段尾 [对方后台发消息] 主线名 | 内容 | t2 → [返回主页]
[打开聊天] 主线 → 主线B（她回头+立边界+邀约）→ [返回主页]
[打开聊天] 粉丝-龙龙 → 三句框架+[发送图片] 图片=脱单教程 | 打开=否 +扣6 → 段尾 [对方后台发消息] 主线名 | 内容 | t3 → [返回主页]
[打开聊天] 主线 → 收尾（确认邀约+边界感一句）→ [打字不发] 下课字幕 | 1.5 → [删除文字] -1（全片最后一行）
```

## 六、额度（每稿）
步数 ≤200；实时对白 ≥110；[打字不发] 15~16 条；插话 5~8 处；[等待] 0.3 共 6~10 处；贴纸全篇 ≤2（按任务书分配）。
画面：[手机状态栏] 无新消息 ×1（主线A 留白处）；朋友圈三连 [打开对方主页]→[进入对方朋友圈]→[点开图片] 序号=1,1 →[等待] 1.2 ×1（任务书指定处）。

## 七、引流与收尾
- 引流词（关注/扣6/教程）只许出现在粉丝会话与下课字幕。
- 收尾最后一行：`[打字不发] 下课 <含「来找我」方向引流，≤16字> | 1.5` → `[删除文字] -1`。
- 邀约表述全篇唯一，只用任务书给定版本，不得出现第二种说法（时间+地点各只有一个版本）。

## 八、交稿自查（逐条过）
格式 / 额度 / 等待位置 / 插话结构 / 删除后禁对方 / 历史块 7 规则 / 邀约唯一 / 复读禁令 / 台词动作匹配（说朋友圈必先打开朋友圈）/ 时间只前进不倒流 / 引用必先铺垫。
