朋友圈视频放这里
================

把 .mp4 文件放进本目录，然后在脚本 / 场景编辑器里用 /videos/文件名.mp4 引用。

例如（对方朋友圈的一条视频动态）：
  {"date":"08 6月","video":"/videos/demo.mp4","cover":"/images/peer/peer_v1.jpg","text":"随手拍的海"}

脚本里播放：
  [播放视频]            ← 点开当前对方朋友圈里的第 1 个视频动态
  [播放视频] /videos/demo.mp4

说明：
- 支持 mp4（H.264 + AAC 最稳），也支持 http(s) 直链。
- cover 是视频封面图，不填则用该动态的第一张配图或 post.cover。
- 视频只是"播放画面"，成品视频的音轨由 main.py 单独合成，不采集视频原声。
- 本目录里的 *.mp4 已在 .gitignore 里忽略，不会进版本库。
