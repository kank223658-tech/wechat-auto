# 长图模式 · JSON 格式说明

> 一句话：写一段对话 JSON，软件出「正宗微信长图」，再自动加上镜头（逐句下移、换人平移、卡音乐鼓点）变成一个竖屏聊天记录视频。

工作台页面：软件里点顶栏 **🖼 长图**（地址 `/longimg`）。

---

## 一、最小可用示例

```json
{
 "mode": "wx",
 "bgm_path": "/longimg-assets/bgm.mp3",
 "meta": {
  "peer_name": "小雅",
  "peer_avatar": "/images/avatar/dygirl_47.jpg",
  "my_avatar": "/images/avatar/dygirl_49.jpg",
  "badge": "99"
 },
 "blocks": [
  {"side": "peer", "text": "我们还是分手吧", "note": "缺乏安全感"},
  {"side": "peer", "text": "我坚持不下去了", "note": "判断真假"},
  {"side": "me",   "text": "认真的？",       "note": "先试探一下"},
  {"side": "peer", "text": "嗯",             "note": "态度冷淡"},
  {"side": "me",   "text": "如果明天下雨 我就同意你的决定", "note": "出其不意"},
  {"side": "peer", "img": "/images/sets2/s011_01.jpg", "note": "她发来的随手拍"}
 ],
 "ending": {"note": "下课 遇到不会聊的女生就来找我吧", "color": "red"}
}
```

工作台里点「载入示例」也能拿到一份可直接改的配置。

---

## 二、顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | string | 否 | `wx`=JSON 对话出微信长图（默认，推荐）；`longimg`=用自己上传的长图。旧值 `json` 会自动当成 `wx` |
| `bgm_path` | string | 是 | 背景音乐。工作台里选/传的音乐会自动填成 `/longimg-assets/xxx.mp3`；用命令行跑时可直接写 Windows 绝对路径 |
| `meta` | object | 否 | 人物设定（见下） |
| `blocks` | array | `wx` 必填 | 对话内容，一条一个气泡（见下） |
| `ending` | object | 否 | 结尾大字，`{"note": "文案", "color": "red|yellow|blue"}` |
| `intro` | object | 否 | `{"blocks": 2}` 片头滑入时先停几个鼓点再开始挪镜头 |
| `pace` | object | 否 | 节奏参数（见下） |
| `quality` | object | 否 | `{"supersample": 2.0}` 超采样倍数，2.0=两倍渲染再缩，画面更干净、耗时翻倍 |
| `longimg_opts` | object | 否 | `{"zoom": 1.0}` 缩放下限（拉远的下限，1.0=原大）；`pan` 只有 `side` |
| `fade_out` | number | 否 | 结尾音乐淡出秒数，默认 1.2 |
| `longimg` | string | `longimg` 必填 | 整图模式的长图路径/URL |

### meta（人物设定）

| 字段 | 说明 |
|---|---|
| `peer_name` | 对方名字，显示在顶栏中间 |
| `peer_avatar` | 对方头像，写 `/images/avatar/xxx.jpg`（内置 150 张）或 `/longimg-assets/xxx.jpg`（自己传的）。**AI 制片别盲选：照《头像选角表.md》按人设点名，男视角「我」固定用男头** |
| `my_avatar` | 我的头像，同上 |
| `badge` | 顶栏返回箭头旁的灰色角标数字，默认 `99` |

> 选头像先看两份文件（都在 长图模式/ 下）：`头像选角表.md`（按人设精选 34 张 + 禁用清单）、`头像库总览.png`（150 张缩略拼图，绿字序号与选角表一致）。

### blocks（对话）

| 字段 | 类型 | 说明 |
|---|---|---|
| `side` | string | `peer`=她说（气泡在左，灰泡）；`me`=我说（气泡在右，绿泡） |
| `text` | string | 台词。可留空——那就只发图 |
| `img` | string | 这条消息发的是照片，写图片 URL（`/images/sets2/xx.jpg` 是内置图集，`/longimg-assets/xx.jpg` 是自己在工作台传的） |
| `note` | string | 气泡下面那行彩色点评小字。**留空则不显示**。颜色默认自动：她说→蓝、我说→黄 |
| `note_color` | string | 想手动指定点评颜色时写 `blue` / `yellow` / `red` |
| `time` | string | 写这个字段会在该消息前插一条微信的时间分隔灰条，例如 `"昨天 21:30"` |

> 一条消息要么是文字要么是图（不要同时写，写了 `img` 就按图发）。

### pace（节奏）

| 字段 | 默认 | 说明 |
|---|---|---|
| `glide` | 0.36 | 一次镜头位移占几个鼓点（0.36≈半拍内滑完） |
| `min_gap` | 1.15 | 两次挪镜头之间最少隔几秒 |
| `tail_hold` | 2.2 | 结尾（最后一句 + CTA）停住几秒 |
| `max_step` | 3.5 | 单步最长等几个鼓点，超了自动补一滑 |

## 三、镜头是怎么走的（了解它才好调参）

- **逐句下移**：第一句框住一句；同一个人第二句拉远到刚好两句同框；第三句三句同框；再多发就滑动窗口，始终最近三句。
- **换人就换边**：谁来发言，镜头立刻横移到那一侧，句数从 1 重数。
- **头像永远完整**：横向取景会把当前句的头像整颗框进来，装不下就自动拉远一点。
- **底边收紧**：画面底边只留当前气泡和点评字，下面还没读到的那条最多露个头，不会整条暴露。
- **开场**：镜头先罩在图顶（状态栏 + 顶栏 + 第一句），从第一句的**对侧**慢慢横扫到位（左边的话就从右往左），停两个鼓点后才开始逐句走。
- **结尾**：拉远成全景 —— 最后一句 + 点评 + 红字 CTA 完整同框居中。

## 四、两种用法

**① 工作台（推荐）**：软件顶栏 **🖼 长图** → 写对话（或导入 JSON）→ 选音乐 → 「只看长图」确认排版 → 「生成视频」。

**② 命令行**：

```bash
# 1) JSON 对话 → 微信长图（需要软件的前端页面在跑，即 8080 端口）
py 长图模式/wx_export.py --config 我的对话.json --out-dir 输出目录 --tag 我的批次

# 2) 长图 → 视频（BGM 在配置里或命令行给）
py 长图模式/render_longimg.py --wxshot 输出目录/wxshot_我的批次.png \
    --bgm 音乐.mp3 --out 成片.mp4
```

只出关键帧拼图预览（不渲染整段）：给 `render_longimg.py` 加 `--preview-only`。

## 五、常见坑

- **导出长图必须有前端页面在跑**：`wx_export.py` 是用无头浏览器去驱动软件里的仿真微信页面排版的，所以要先启动软件（8080）。工作台会直接提示「前端 8080 未运行」。
- **音乐不能少**：步进是卡在鼓点上的，没音乐就没法对拍。
- **图片用 URL 不用磁盘路径**：写 `/images/sets2/xxx.jpg` 这种页面能访问到的路径；Windows 绝对路径只在命令行模式下给 `--bgm`/`--longimg` 用。
- **点评行不要写冒号**：`态度冷淡：说明她…` 这种会被当成对白上屏，直接写「态度冷淡 说明她…」。
- **一次改一个变量**：镜头是按句数定标的，句子增删会改变所有落点，调参后建议先「关键帧预览」再出片。
- **画质与耗时**：`supersample` 2.0 是默认；长图特别长（消息特别多）时会自动降档，避免内存爆掉。
