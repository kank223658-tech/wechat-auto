# 长图模式 使用说明书

> 2026-09-15 上线 v1。复刻抖音「直男许诺」聊天记录长图类视频的全自动生产线：
> **长图 / JSON → 鼓点卡点片头 + 步进滚动 + BGM → 横屏成片**。

## 一、对标逆向结论（一切设计以此为准）

拆解对象：《当女生下定决心要跟你分开该怎么回复》（1920×1080 横屏 30fps 105.8s）。

| 机制 | 实测结论 |
| --- | --- |
| 画面 | 纯黑底；对方=深灰泡(#2D2D2D)白字+左圆头像；我方=微信绿泡黑字+右圆头像；单行泡高 278px、字号约 100px |
| 点评行 | 每颗泡正下方一行彩色大字：**蓝=点评她/形势，黄=点评我方操作，红=结尾 CTA** |
| 顶栏 | `< 1` 徽标 + 右侧对方头像/名字，**是长图的一部分，会随滚动移出画面** |
| 滚动 | 步进式：每步 0.3~0.4s 缓动滑 + 停到下一拍；全片 54 步 |
| ★核心 | **滚动落点与 BGM 强鼓点逐一重合**（4.7 / 8.45 / 10.32 …秒），不是匀速也不是定时器 |
| 片头 | 0~4.6s：顶栏先出 → 前几条消息按拍从侧边滑入（卡点钩子） |

## 二、三种用法

### 1. 编辑器工作台（推荐）
1. 软件顶栏点 **🖼 长图**（或浏览器打开 `http://localhost:8000/longimg`，独立窗口，工作流编辑器顶栏有入口按钮）。
2. 「JSON 对话」页签：逐条添加 她/我 台词 + 点评行（颜色自动），每条还能「选图」发照片；或「载入示例 / 导入 JSON」；
   或切「上传整张长图」页签。左下「JSON 配置」区表格↔JSON 双向同步，格式见页面右下「📖 JSON 格式说明」
   （源文件：`长图模式/JSON格式说明.md`）。
3. 选/传 BGM → 调节奏参数 → 「🖼 只看长图」（出正宗微信仿真长图，排版即所见）→「🎞 关键帧预览」→「⏺ 生成视频」。
4. 任务卡片完成后直接在线播放/下载；成片与长图都在 `vue-WeChat/public/videos/longimg/`。
5. 头像可在内置 150 张头像库里点选，也能自己传；对方名/角标（默认 99）可改。
6. 出片链路：JSON → `wx_export.py` 正宗微信长图（真微信样式+DOM 坐标真值）→ `render_longimg.py --wxshot` 动态镜头
   （逐句句数定标、换人平移、开场横扫、底边收紧、头像整颗入画、卡 BGM 鼓点）→ MP4。

### 2. 命令行（微信长图模式）
```
py 长图模式/wx_export.py --config 配置.json --out-dir 输出目录 --tag 批次名
py 长图模式/render_longimg.py --wxshot 输出目录/wxshot_批次名.png --bgm 音乐.mp3 --out 成片.mp4
```

### 3. 命令行（整图模式）
```
py 长图模式/render_longimg.py --config 配置.json --out videos/xxx.mp4
py 长图模式/render_longimg.py --config 配置.json --preview-only   # 只出 6 宫格关键帧
```

### 3. 命令行（整图模式：放大 + 左右平移）
```
py 长图模式/render_longimg.py --longimg 长图.png --bgm 音乐.mp3 --out videos/xxx.mp4
```
放大/平移由配置 `longimg_opts` 控制（命令行 `--config` 或编辑器 API 传入）：
```jsonc
"longimg_opts": {
  "zoom": 1.05,     // 拉远下限 1.0~2.5；镜头缩放全自动，此值只限制拉远的下限
  "pan":  "side"    // side=跟人走（她说→贴左 我说→贴右）| center=不移动只缩放
}
```
工作台「整张长图」页签里也有这两个控件（拉远下限滑杆 + 左右移动下拉）。
**动态镜头语言（v1.4）**：一句一挪卡鼓点；单句/换人→自动拉近（最高 4.2x，
且保证气泡完整不裁字）；同侧连发→自动拉远看全连发段（受拉远下限约束）；
每步取景=当前句+同侧后面最多 3 句，阅读位置始终偏上（第一句顶上去）。
内容块识别用「暗色文字」判据（中位数定侧向、2%/98% 分位定水平范围），
真实微信截图（彩色渐变背景、白泡/绿泡）都能正确定位；状态栏/时间戳自动过滤。
开场对标手法：镜头拉近停在第一条消息、x 在其**对侧**，第一拍慢慢滑过去（约 0.9s）。

## 三、JSON 配置格式

> ★ 最新最全的字段说明在 **`长图模式/JSON格式说明.md`**（工作台页面右下角也有同款说明），下面是历史速查版。

```jsonc
{
  "meta": {                          // 元信息（整图模式忽略）
    "peer_name": "小雅",
    "peer_avatar": "/images/avatar/dygirl_47.jpg",   // 支持 /images/ web 路径
    "my_avatar": "/images/avatar/dygirl_49.jpg",
    "badge": "1"                     // 左上角徽标数字
  },
  "blocks": [                        // 消息块，按顺序
    {"side": "peer", "text": "我们还是分手吧", "note": "缺乏安全感"},
    {"side": "me",   "text": "认真的？",       "note": "先试探一下"},
    {"side": "peer", "img": "/images/xxx.jpg", "note": "可选"}   // 图片块
  ],                                 // note_color 可选 blue|yellow|orange|red（默认自动：她说→蓝、我说→黄）
  "ending": {"note": "下课 遇到不会聊的女生就来找我吧", "color": "red"},
  "bgm":    {"path": "音乐.mp3", "fade_out": 1.2},   // 太短自动循环
  "intro":  {"blocks": 2},           // 片头按拍滑入的消息条数 0~3
  "pace":   {"glide": 0.36,          // 每步滑动时长(秒)
             "min_gap": 1.15,        // 两拍最小间隔
             "max_step": 3.5,        // 音乐空拍超此秒数自动补一滑
             "tail_hold": 2.2}       // 结尾停留
}
```

- BGM 太短：按块数自动压缩步距；鼓点不足：按中位步距补拍。
- 成片时长 = 最后一步落点 + tail_hold，BGM 结尾自动淡出。

## 四、文件分工

| 文件 | 职责 |
| --- | --- |
| `chat_canvas.py` | JSON → 长图（分层：每块独立 RGBA，供片头滑入）；样式常量都在文件头 |
| `beat_grid.py` | scipy 谱通量 onset 检测 → 强拍；plan_step_beats 挑滚动落点 |
| `render_longimg.py` | CLI 主程序：时间轴 → PIL 逐帧 → rawvideo 管道喂 ffmpeg → 混 BGM |
| `longimg_api.py` | 编辑器 API/静态路由；`editor_server.py` 的 do_GET/do_POST 开头各接入一次 |
| `sample_config.json` | 工作台「载入示例」的数据源 |
| `editor/longimg.html` | 工作台页面（`/longimg`） |
