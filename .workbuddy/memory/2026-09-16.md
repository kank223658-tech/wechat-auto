## 聊天背景随键盘上移 bug（用户报告：气泡铺满时开键盘，背景跟着整体上移）
- ★根因：`transfer_detail.css` 给 `.dialogue-section` **无条件常驻** `will-change: transform`（转账页视差防鬼影需要）→ 按 CSS 规范，元素上有 transform/will-change 时 `background-attachment: fixed` **退化成 scroll**。chat_exact.css 里「背景钉视口」的旧防线整个失效，背景实际贴在消息区盒子上：盒子高度随键盘开合 1019↔553 变化，cover 按新盒子反复重裁 → 观感「背景跟着上移」。
- ★修法（chat_exact.css）：背景从会滚动/会变高的 `.dialogue-section` 搬到**永不滚动、不变形的 `.dialogue` 容器 `::before`**（`html body.wx-chat .dialogue::before`，inset 铺满 + `background: var(--wx-chat-bg,#101010)`）；`.dialogue-section` 改 `background: transparent`。键盘/滚动/输入框增高都只动内容层。
- 转账详情视差联动（transfer_detail.css）：`body.wx-tfd-open/close .dialogue::before` 同帧同曲线 translate3d(-30%)，避免推入详情页时「气泡左移、背景不动」撕开感。
- ★验证法（_工作文件\_kbtest_bg.py，可复用）：真渲染器 `WeChatAuto(headless=True).start()` 直连页面；10 条 130px 递增灰阶横带 data URL 当壁纸（setChatBg），26 条对方短消息撑溢出；`bot._kb_show/_kb_hide` 生产路径开合键盘；在**纯背景竖条**（x 510~592，y 240~560，避开键盘/悬浮胶囊/气泡）取行均值剖面互相关求 dy。结果：新 dy=0 mse=0（逐像素不动）、旧(注回) dy=-134（bug 复现）、默认深色 dy=0（无回归）。
- ★教训：测量窗口必须避开弹出键盘（第一次把键盘算进剖面 → 假位移）；A/B 对照（注回旧 CSS）是证明「测对了」的关键。
- 注意：改 enhance 须重启常驻渲染器（8001/editmode）；editor_server 每次跑批新起 main.py 进程 → 自动生效。
