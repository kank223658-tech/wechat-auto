# 桥段库·片段收集体例（0919 用户定调：精彩对话片段库 → 直接照搬）

## 为什么建这个
写稿无聊的根因：现有金样全出自同一博主，怎么重组天花板都在那。**精彩度上限=素材精彩度**。
你负责供"弹药"（真实精彩的男女对话片段），我负责选段+缝合+合规——我的角色从编剧变剪辑师。

## 怎么给片段（格式随意，下面是最好用的版式）
```
【场景】什么时候/什么关系（刚加上第2晚 / 相亲后 / 她主动找的）
【前因】她为什么发这句（一两句话，让我知道接什么）
——
她：她发的原话
我：我回的原话
她：...
——
【亮点】一句话说清这段妙在哪（可选：反将 / 装傻 / 图梗 / 反转 / 欲擒故纵）
```
- **不用整理、不用想标签**，微信截图转文字、随手粘贴都行；唯一要求：**别删减对话原句**，照搬是我的口粮
- 一段 3~20 条消息都收；同一个片段里最精彩的哪句，可以标一下

## 量与质
- 目标 **50~200 段**，越杂越好：不同关系阶段（刚加/聊了三天/暧昧期/降温挽回）× 不同招式（开场/反将/推拉/邀约/哄睡/图梗/反转）
- 撞句式的自动去重（门禁本来就卡复读）；同招式片段多 = 我每篇能换着用，不重样

## 拿到片段后我做什么
1. 打标签入库（create.db 桥段机制现成，直接挂）
2. 写稿时按「拍子」检索：这个位置该反将了 → 拉出反将片段池 → 挑一段
3. **对话原句直接照搬**，只改三样：人名、话题锚点（让她的话接得住上文）、承接句
4. 机械门保证格式/指标全绿，杜绝"编出来的味"

## 文件存放
- 片段 md/txt 直接丢进 `剧本库\_桥段库\`（本目录），我来解析入库
- 也支持直接在对话里粘贴，我收一段存一段
