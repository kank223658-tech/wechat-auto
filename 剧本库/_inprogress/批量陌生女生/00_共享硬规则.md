# 批量陌生女生 · 共享硬规则（每稿写前必读、交稿逐条自查）

> 本批 10 篇统一题材：**陌生女生 / 刚加的女生怎么聊**（对应参考案例《不认识的女生怎么追》那一套的路子）。
> 结构沿用剧本制作组 v3 固定骨架，字幕风格对标 `剧本库\不认识的女生怎么追（参考原文）.txt`。

## 一、行格式
- 一行一条指令，格式 `[动作名] 参数`，多段参数用「|」分隔。
- 允许的动作全集（别的都不许用）：
  `[历史会话]`…`[历史会话结束]`、`[会话] 名`、`[打开聊天] 名`、`[返回主页]`、
  `[我方打字] 内容`、`[对方发消息] 内容`、`[打字不发] 字幕 | 0.5 | 插话（第3段可省）`、`[删除文字] -1`、
  `[等待] 0.2`、`[对方后台发消息] 名 | 内容 | HH:MM`、
  `[发送表情] 短名`、`[对方表情] 短名`、
  `[发送图片] 图片=<描述> | 打开=否`（仅粉丝会话）、`[对方发图片] 图片=<描述> | 打开=是 | 停留=1.2`、
  `[手机状态栏] 无新消息`、`[打开对方主页] 名`、`[进入对方朋友圈]`、`[点开图片] 序号=1,1`、`[等待] 1.2`
- **禁用**：闪回聊天、我方发链接、转账、语音、加入黑名单等一切不在此清单的动作。
- 历史块里已出现的图/表情，实时段绝不再发（**双投=打回**）。

## 二、[打字不发] 与插话
- 格式 `[打字不发] 字幕 | 0.5`，常规**一律 0.5**（仅合并长字幕 / 需要观众读完的博弈大窗口用 1.0~1.5）；每条后紧跟 `[删除文字] -1`。
- **字幕=给观众看的短语标签**：主体 2~10 字（硬上限 14），「动作短语 + 空格 + 三五字补充」。金样（全部取自用户认可的真实成稿）：
  `接住不破防 / 顺着结论走 / 她等你追 你偏不追 / 回头也慢半拍 / 别哄太满 立边界 / 暗示见面 / 学以致用`
  `礼貌开场 / 勾起好奇心 / 试探一下 看反应 / 曲解意思 引入新话题 / 接成体贴 / 留白 收放有度`
  **禁止** 15+ 字解释句（反面教材：`她回头了 慢半拍才显你不在围着她转`、`不破防 她反而不习惯 节奏回到你这`）。
  自检：逐条数字数，超 10 字先砍成两三个词，超 14 字必须重写。引流 CTA / 下课字幕可放宽到 16 字左右。
- 插话=**她**发来的消息，全部收进第 3 段，多段用「；」，只能是她台词。
  ★ **视角铁律（2026-09-14 用户当场抓）**：第 3 段是**她发来的消息**（画面=她的气泡），她的话里「我」=她自己、「你」=我。**严禁**写进插话的三类东西：① 我方心理活动（「这是明着钓我」「吊着我」「明明在等我；还嘴硬」）；② 我方教学策略（「见好就收」「看你怎么圆」「不如挑刺」）；③ 对她刚发的东西的点评（「就这光线 也敢发？」——点评她的自拍是我的活儿）。也**不要复述她上一条已经说过的话**。④ **边界写法**：通篇没有「我/你」、没有语气词/问句、读起来像备注（「带钩的问题；先给证据再收」「三点 别忘」）——她的话一定带人称或语气。校验器 **3.12** 对 ①②③④ 直接判问题、对「复述上一条」给提示。
  ★ **承接铁律（2026-09-14 用户当场抓）**：插话的锚点只有两个——**我上一条已经发出去的消息**、或她自己起的新话题。**还停在输入框里的草稿她看不到，不能当她的锚点**（旧版写成"她对没发出去的字的反应"，是反复出错的根因）。**我删掉草稿后发的那句，必须是她的答**。自查两句：她为什么要在这时候说这句？我这两句答得上吗？反例：她只说「疼死了都[大哭]」→ 我「这事怪我」（她没怪过我）；插话「关你什么事」而上文我最后一条是「我这人最听话」（没人管过她）。校验器 **3.13** 判问题：回应型孤立句／认责句空降／答非所问。
  唯一合法结构：`[打字不发] 字幕 | 0.5 | 反应1；反应2` → `[删除文字] -1`
  **[删除文字] 之后、下一个我方动作之前，禁止任何 [对方×] 行**（`[对方后台发消息]` 是跨会话机制，豁免）。

## 三、节奏与对白
- 对方相邻连发两条（中间无其他动作）之间必须插 `[等待] 0.2`（2026-09-14 晚定标 0.3→0.2）；我方消息之间不加。
- `[我方打字]` 口语 ≤20 字；要有连发 2~3 条的段落，别写成严格一问一答；交替率 ≤0.75。
- **复读禁令**：同一句话全篇不出现第 2 次；同一句式（如「你倒是会X」「你变了」）全篇最多 3 次。
- 3D emoji 内嵌进消息文本（如「行吧[Emm]」），每个全篇只用 1 次。
- 方法论 / 心理活动**绝不进聊天正文**，只进 [打字不发] 字幕。

## 四、历史块（10 个 [会话]，`[历史会话]` 开头 / `[历史会话结束]` 收尾）
- 按最后一条消息时间**从新到旧**排；同一人只一个会话；同一会话只有**首末条**带「| HH:MM」且间隔 ≥5 分钟，**末条必带时间**；同一人连发 ≤2 条；**★至少 1 个会话必须有「我：」回复（对方说 → 我回 → 对方再说），漏了 = 机械门直接判失败**；固定给粉丝会话写三段：「粉丝：链接 / 我：一句话 / 粉丝：末条|时间」；禁「在吗 / 哈哈 / 吃了吗 / 晚安」空话，每条都要有钩子。
- 粉丝会话必含：`[对方发链接] 聊天案例解析（必看） | 随机 | 恋爱技巧 | HH:MM`。
- 其中 1 个会话放系统消息：`某名：我通过了你的朋友验证请求，现在我们可以开始聊天了 | HH:MM`。
- 历史块时间一律早于实时段第一时间条；全篇时间只前进、不倒流。
