# 链接卡片功能演示（[我方发链接] / [对方发链接]）
# ============================================================
# 用法（文本剧本）：
#   [我方发链接] 标题                          -> 图片按「标题里的字」自动匹配
#   [我方发链接] 标题 | 图片名/路径             -> 显式指定卡片缩略图
#   [我方发链接] 标题 | 图片 | 来源名           -> 同时替换来源名（默认「心灵知行」）
#   [对方发链接] ...                           -> 对方发送（气泡在左）
# 末尾追加 ` | 18:22` 可加时间分隔条（见最后一条）。
#
# 图片自动匹配规则：
#   · 把方形缩略图放进  vue-WeChat/public/images/link/  目录；
#   · 文件名带一个能代表链接主题的关键词（如 男生.jpg / 脱单.jpg）；
#   · 标题里出现该关键词即自动命中；
#   · 也可在 link_library.json 里登记 {url, name, keywords} 做更精准匹配。
# ============================================================
