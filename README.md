# 仿微信界面全自动操作 + 录屏脚本（键盘模拟版）

基于 **Playwright（同步 API）** 驱动开源项目 [vue-WeChat](https://github.com/zhaohaodang/vue-WeChat)
（纯前端 Vue2 仿微信界面），模拟真人操作，全程录制**单条完整视频**并输出 MP4。

两大核心能力：

1. **真实键盘打字**：页面注入手机 QWERTY 键盘覆盖层，中文按「拼音逐键高亮 → 候选词条 →
   点击上屏」的流程，英文逐键高亮，录出来的视频和手机录屏一致。
2. **影刀式工作流编辑器**：可视化「动作库 + 步骤列表 + 参数表单」，点几下就能编排一段
   "打开聊天 → 打字 → 对方回消息 → 进朋友圈 → 点赞评论 → 改头像背景 → 发朋友圈" 的流程，
   一键运行生成视频。

## 目录结构

```
weixin-auto\
├── main.py               # 自动化执行器（读取剧本/工作流，驱动浏览器+录屏）
├── editor_server.py      # 工作流编辑器本地服务（影刀式可视化编排 + 脚本模式 API）
├── script_translator.py  # 内置 DeepSeek 剧本转译引擎（LLM 转译 + 离线兜底）
├── editor\index.html     # 编辑器界面（工作流编辑 + 脚本模式）
├── enhance\              # 注入式前端增强：手机键盘/配置/朋友圈扩展/样式
├── script.txt            # 旧版文本剧本（仍可用）
├── scene.json            # 独立场景编辑器读写的数据（我的资料+会话消息+朋友圈）
├── editor\scene.html     # 独立场景编辑器（可放大、点选即改、编排联系人/消息）
├── workflow.json         # 可视化编辑器保存的工作流（运行入口）
├── settings.json         # 脚本模式配置（DeepSeek API Key / 模型，只存本地）
├── videos\               # 录屏输出目录
└── vue-WeChat\           # 被操作的前端项目
```

## 三、四种使用方式

### 方式一：可视化工作流编辑器（推荐）

```bat
start_all.bat editor
:: 或 py editor_server.py
```

浏览器自动打开 `http://localhost:8000`：

- **左侧**动作库：按分类点击添加动作（聊天/导航/朋友圈/个人资料/系统）
- **中间**步骤列表：上移 / 下移 / 复制 / 删除
- **右侧**参数表单：点中步骤后编辑参数
- **顶部**：保存 → 载入 → **运行并生成视频** → 打开视频目录
- **底部**：实时运行日志，完成后自动显示视频文件

编辑器保存到 `workflow.json`，运行即在真实浏览器里逐步执行并录屏。

#### 编辑模式：直接修改手机画面上的元素

点顶部 **✏️ 编辑模式**，会在编辑器右侧弹出「实时手机画面」浮窗，无需跑流程就能直接改屏幕内容：

1. 画面默认是 **👆 操作** 模式：点击画面 = 点击手机屏幕，可进聊天、切 Tab、翻页；
2. 切到 **✎ 编辑** 模式后，点击画面中的元素会弹出修改框，改完点「保存」立即上屏：
   - **文字**：聊天列表昵称/最后一条消息、聊天气泡、朋友圈正文、评论等，直接改文字；
   - **图片**：头像、配图等，填图片路径（放在 `vue-WeChat/public/images` 下的路径）；
   - **我的资料**：头像/昵称/朋友圈封面，改后全局同步（主页、通讯录、朋友圈一起变）；
3. 底部输入栏可向手机当前聚焦的输入框打字（先点一下聊天输入框聚焦）；
4. 改完后点 **⏹ 退出编辑模式**，或直接编排工作流运行录屏。

> 说明：编辑模式只是实时预览修改，改完不写入 workflow.json。
> 要让修改在每次运行都生效，请用对应的动作（`编辑主页`、`编辑朋友圈`、`修改昵称`、`设置头像`、`设置背景` 等）编排流程。

### 方式二：文本剧本（旧格式，仍兼容）

```bat
py main.py                       # 读取 script.txt
python main.py --script 我的剧本.txt
python main.py --headless        # 无头模式
python main.py --headless --speed 2   # 无头 + 2 倍速（更快出片）
```

### 方式三：脚本模式（内置 DeepSeek 剧本转译引擎）

在编辑器顶部切到 **脚本模式**：粘贴剧本（标准格式或松散自然语言），点
**AI 转译剧本** 由内置 DeepSeek 大模型（`deepseek-flash`）自动补全仿真动作，
预览确认后一键运行录屏。没有 API Key 时自动降级为离线规则解析，标准格式剧本照常可用。

使用流程：

1. 顶部切到 **脚本模式**，点 **⚙ 配置大模型** 填入 DeepSeek API Key（模型默认
   `deepseek-flash`，可改为 `deepseek-v4-pro` 等）。Key 只保存在本机
   `settings.json`，界面不回显明文；也可以设置环境变量 `DEEPSEEK_API_KEY` 代替。
2. 在左侧大文本框粘贴剧本。既支持标准指令格式（见下表），也支持自然语言叙述，例如：
   > 我和陆香儿聊了下周聚餐的事，她说周三有空，我回复好的到时候见。
3. 点 **🤖 AI 转译剧本**：大模型会自动补全——
   - 对话前缺省补 `[打开聊天]`，`[对方发消息]` 前补 `[对方正在输入]`；
   - 页面切换/动作之间补 `[等待]`（0.3~0.8s），剧本里写明的等待时长原样保留；
   - 剧本里出现默认名单之外的联系人（如“小明”）时，开头自动生成一条
     `[编辑主页]` 重建会话列表，保证后面能进得去；
   - 消息内容与联系人名原样保留，不改写。
4. 右侧预览转译结果：可上移 / 下移 / 删除，点卡片可编辑参数（JSON）；
   有疑问的项会以黄色横幅提示。确认无误后点 **▶ 运行并生成视频**。
5. 没有 Key 或断网时，点 **⚙ 离线解析** 仍能按标准格式解析剧本并正常运行。

> 说明：转译结果只替换本次运行的内容，不会改动左侧“工作流编辑”里的流程。

#### 人物库（学员 / 美女 两类）与自动替换

人物库 `people.json` 里的人物只分两类：**美女**、**学员**，界面按两个分区展示，绝不混用。
每次点「AI 转译剧本」都会**重新读取**人物库（你随时更新都生效）。

- **剧本里写的人名，若人物库里就有**：直接用这个人和它的头像，不改动。
- **剧本里写的人名，人物库里没有**（常见于写错、或剧本用了库外名字）：自动把它替换成
  **同类别（美女→美女、学员→学员）** 的库中人物，整段对话内容原样保留，只换人名，并优先
  挑这个剧本里还没用过的人。库中没有同类别可替换时才保留原名并给出提示。
- **判定类别**：人名里含「学员 / 学生 / 同学 / 粉丝」等字样 → 归入**学员**；否则 → **美女**。
- **联系人名的唯一来源是人物库 `people.json`**（美女 / 学员 两类）。剧本里写的人名若在
  人物库中，直接沿用其名字和头像；不在库中则被自动替换成**同类别**的库中人物（学员→学员、
  美女→美女）。当前场景（`scene.json`）里已有的联系人同样可以直接用。

> 提示：想让某个库外名字不被替换，就把它加进人物库（在场景编辑器「👥 人物库」新增，或在
> 「会话」给联系人选头像后点顶栏「💾 保存到人物库」），转译时就会沿用这个名字和头像。

### 方式四：独立场景编辑器（推荐编排整机内容）

```bat
start_all.bat scene
:: 或 py editor_server.py --open-scene，再在浏览器访问 http://localhost:8000/scene
```

这是一个**独立、可放大**的场景编辑器页面（在工作流编辑器顶部点「🎬 场景编辑器」也会打开），
纯前端按 `scene.json` 数据渲染整个手机界面：

- **点选即改**：直接点手机画面里的任意元素（联系人名、最后一条消息、聊天气泡、朋友圈文案/头像/封面），弹出编辑框修改。
- **可放大**：滚轮缩放、拖拽平移，`＋/－/适应` 控件。
- **结构化编辑**：右侧 `会话 / 消息 / 朋友圈 / 对方主页 / 我的资料` 五个 tab：
  - 会话：增删排序聊天列表项，改名字/头像/未读/免打扰/私聊或群聊；
  - 消息：逐个会话编写消息历史，可指定**发送方向（我/对方）**、类型（文字/图片/语音）、内容、时间；点「对方连发一长串」一次插入多条对方消息；
  - 朋友圈：增删排序动态，改作者/文案/配图/时间/点赞/评论；
  - 对方主页：**多人物 × 多方案**——①人物列表（每个联系人可有自己的主页和朋友圈，新建/复制/删除/从预设新建）；②编辑方案（同一人物可备 A/B/C 多套朋友圈内容，一键切换预览，生成工作流只导出当前方案）；③动态列表（当前方案的动态增删/排序/加视频/点赞/评论）。另有**模板一键生成**（日常自拍/旅拍打卡/美食探店/健身运动/创业正能量，自动生成 6 条动态：模板文案+图片库配图+日期错落）与 **AI 文案**（配 DeepSeek Key 后按关键词重写整套文案）；老场景的单 peer 数据自动迁移，完全兼容；
  - 我的资料：照片/昵称/签名/朋友圈封面（图片从 `/api/gallery` 下拉选择）。
- **图片库分类管理**：图片库与选图弹窗都按分类筛选——**头像 / 表情包 / emoji / 背景 / 配图素材 / 系统图标 / 🎬视频**。
  - 上传时先选「存到 · 某分类」，图片会落进对应目录（`public/images/avatar|sticker|emoji|bg|asset/`），选择会自动记住；
  - 选中图片后可「📂 移动到分类」，真正搬移文件并**自动更新** `scene.json` / `workflow.json` / `people.json` / `enhance/config.js` 里的旧路径引用；
  - 「🎬 视频」分类列出 `public/videos/` 下的视频素材，发朋友圈视频动态 / `[播放视频]` 时直接选。
- **保存 / 应用**：`保存场景` 写入 `scene.json`；`生成工作流` 自动产出 `编辑主页`+`编辑朋友圈`+个人资料等步骤写入 `workflow.json`，随后即可 `▶ 运行并生成视频`。

> 场景与运行：`scene.json` 描述整个手机内容；运行时可在 `main.py --scene scene.json` 开头应用，
> 或用工作流里的 `[应用场景]` / `[编辑主页]`（带 `messages`）把编排好的消息历史精确还原到手机，
> 聊天历史里「我」显示为右侧绿色气泡、「对方」为左侧白气泡。

## 三·五、界面内离线使用手册（📖）

编辑器顶部点 **📖 使用手册**，即可打开一份**离线**（不联网）的完整说明，覆盖：

- 三种模式（工作流编辑 / 脚本模式 / ✨ 创作）怎么用；
- 全部动作库动作 + 文本剧本指令的**书写格式、参数、示例**；
- 时间标注、对方插话、图片/表情/语音/链接标记、历史会话块等写法；
- 场景编辑器、并发生产、编辑模式、运行确认框、人物库、素材路径与常见问题。

手册带**搜索**，输入「打字 / 朋友圈 / 时间 / 链接」等关键词即可定位。

> 🔧 **新增功能时请同步手册**：手册内容全部放在 `editor/manual.js`，按分类的 `items` 追加一条
> `{ name, tag, syntax, desc, bullets, example }` 即可；新增分类就在 `categories` 里加一项。
> 改完更新文件顶部 `updatedAt`，无需改动其它代码。

## 四、文本剧本指令一览（与编辑器动作一一对应）

| 指令 | 参数 | 说明 |
| ---- | ---- | ---- |
| `[打开聊天]` | 联系人名称 | 从聊天列表点击进入指定会话 |
| `[我方打字]` | 文字内容 | 手机键盘动画打字（拼音+候选），回车发送 |
| `[打字不发]` | 文字内容 | 键盘打字但**不发送**，停在输入框展示 |
| `[删除文字]` | 字符数 / 全部 | 退格键逐个删除输入框内容 |
| `[对方正在输入]` | 秒数 | 聊天头部显示「对方正在输入...」 |
| `[对方发消息]` | 文字内容 | 对方消息以左侧白色气泡上屏 |
| `[对方后台发消息]` | 联系人 \| 内容 | 给**当前不在看的会话**投递对方消息，画面不变，仅刷新该会话在主页的预览+未读角标（返回主页可看到） |
| `[后台消息队列]` | JSON 数组 | 装载一批后台消息并**立刻**在后台发出去：执行到这一行时，每条消息马上投递给对应会话，刷新主页预览+未读角标，之后打开即可看到 |
| `[切换Tab]` | 微信/通讯录/发现/我 | 点击底部 Tab |
| `[返回主页]` | 无 | 切回聊天列表主页 |
| `[隐藏键盘]` | 无 | 收起手机键盘 |
| `[进入朋友圈]` | 无 | 从发现页进入朋友圈 |
| `[向下滚动]` | 像素值 | 鼠标滚轮自然下滚（朋友圈 / 对方朋友圈均可） |
| `[向上滚动]` | 像素值 | 鼠标滚轮自然上滚 |
| `[滚动到]` | 顶部 / 底部 | 把对方朋友圈滚到顶/底 |
| `[点开图片]` | 序号（可空，如 `2,3`） | 点开朋友圈动态里的配图全屏查看（对方朋友圈优先）；`2,3` = 第 2 条第 3 张，留空 = 第 1 条第 1 张 |
| `[打开对方主页]` | 人设名（可空） | 点对方消息头像 → 推入「对方个人资料页」 |
| `[进入对方朋友圈]` | 无 | 资料页点「朋友圈」行 → 推入对方朋友圈 |
| `[编辑对方资料]` | 预设名 / JSON / .json | 整体替换对方的资料与朋友圈；动态加 `video` 即为视频动态 |
| `[播放视频]` | 视频地址（可空） | 点开朋友圈视频全屏播放；留空则点开朋友圈里第 1 个视频动态 |
| `[闪回聊天]` | 停留 / 闪白 | **硬切**回聊天页（不做滑出转场），观感像视频剪辑的一次切镜 |
| `[返回上一页]` | 无 | 对方朋友圈 → 资料页 → 聊天页（iOS 推出转场） |
| `[点赞]` | 无 | 给最后一条动态点赞 |
| `[评论]` | 评论文字 | 键盘动画打字发表评论 |
| `[发朋友圈]` | 文案 | 发表文字朋友圈（打字+发表上屏） |
| `[编辑朋友圈]` | JSON / .json 文件 | 按数据重建动态（昵称/文案/图片/点赞/评论） |
| `[编辑主页]` | JSON / .json 文件 | 按数据重建会话列表（含 messages 可精确还原双方消息历史） |
| `[应用场景]` | 场景对象 / scene.json | 一步应用 我的资料+主页会话(含消息)+朋友圈 |
| `[编辑会话]` | JSON / .json 文件 | 编辑会话消息历史（我/对方、文字/图片/语音） |
| `[设置头像]` | 图片路径 | 修改头像（所有位置即时更新） |
| `[设置背景]` | 图片路径 | 修改朋友圈封面背景 |
| `[等待]` | 秒数 | 自然等待 |

以 `#` 开头的行是注释。可用图片需放在 `vue-WeChat/public/images/` 下（如
`/images/avatar/`、`/images/bg/` 里的真实文件，可在场景编辑器图片库中查看），也可自行放图片到该目录后填写路径。

> 🎬 对方主页 / 对方朋友圈：`[编辑对方资料]` 的数据里，`posts[]` 每条动态可写
> `date` / `images[]` / `text`，加一个 `video` 字段就是视频动态——
> `{"date":"08 6月","video":"/videos/demo.mp4","cover":"/images/peer/peer_v1.jpg","text":"随手拍的海"}`。
> 视频动态在朋友圈里显示「封面 + 播放角标」，`[播放视频]` 会点开全屏播放（带进度条与时长），
> 朋友圈里的图片也都能点开放大查看（真人式放大/停留/关闭）：`[点开图片] 2,3` 点开第 2 条动态的
> 第 3 张配图，留空则点开第 1 条第 1 张。视频文件放在
> `vue-WeChat/public/videos/` 下，用 `/videos/xxx.mp4` 引用（也支持 http(s) 地址）。
> 完整可运行示例见 `script_moments.txt`（从「发现」进朋友圈）和 `script_peer_moments.txt`
> （聊天页点对方头像 → 对方主页 → 对方朋友圈 → 看图片/播视频 → 闪回聊天）。
> 看完朋友圈想直接切回聊天接着录，用 `[闪回聊天]`：它**不做滑出转场**，一帧切回聊天页，
> 观感就像剪辑软件里的一次硬切；`[闪回聊天] 香儿` 还能闪回后直接进该会话，加 `闪白=是`
> 则会在切镜瞬间闪一帧白。

> 🕒 时间标注（时间分隔条占位）：任何**会产生会话消息**的动作（`[我方打字]` / `[对方发消息]` /
> `[对方后台发消息]` / `[后台消息队列]`）在参数末尾加 `| 时间`，就会在这条消息前显示一条
> 微信灰色时间分隔条，如 `[我方打字] 我下班了 | 18:22`。支持 `18:22`、`昨天 23:52`、
> `星期三 20:00`、`6月8日 18:22`、`35分钟前`、`2天前` 等写法。**只有标注了时间的消息才显示
> 分隔条**，不再有自动规则；历史会话块里也可写 `说话人：内容 | 时间`。时间要写在最后
> （`内容 | 时间`），与「停留/插话」的 `|` 共用时段时可写 `[打字不发] 内容 | 0.3 | 18:20`。
> 注意：`[打字不发]` 只是"打字不发"、消息不上屏，因此不显示时间分隔条。

> ⚠️ 联系人名：系统**没有**硬编码的默认联系人名单——首页会话列表由 `scene.json` 场景数据
> 重建，人物名与头像以**人物库 `people.json`** 为唯一来源（库外名字在 AI 转译时会被自动
> 替换成同类别库中人物）。直接运行文本剧本时，`[打开聊天]` 只能填当前场景里真实存在的
> 名字，或先在流程里加一步 `[编辑主页]`（数据见 `reference_workflow.json`）重建列表。

> 💬 后台消息：`[对方后台发消息] 陆香儿 | 内容` 给「当前不在看的会话」投递对方消息，画面不变，
> 只把该会话在主页的预览和未读角标（含底部「微信」角标、标题「微信 (N)」）刷新，之后 `[返回主页]`
> 就能看到、点进去即可阅读。`[后台消息队列]` 的每条消息也在执行到该行时**立刻后台发出**，形如
> `[后台消息队列] [{"联系":"陆香儿","内容":"图片怎么发您"},{"联系":"妍","内容":"有空吗"}]`（无需写 `触发`，
> 队列按"装载即投递"处理，避免按秒/步延迟在短剧本里永远收不到）。队列里的联系人
> 需存在于主页列表，转译/运行前会自动补进 `[编辑主页]`。

直接跑一段完整演示（多轮聊天 + 切换聊天 + 朋友圈点赞评论并录屏）：

## 五、实现说明

- **键盘模拟**：`enhance/keyboard.js` 注入手机 QWERTY 键盘（固定底部、弹出动画、按键高亮），
  中文用 `pypinyin` 转拼音，逐个敲拼音键后弹出候选词条，点击候选上屏；真实键盘事件仍由
  Playwright 发出，保证输入框内容与画面一致。
- **剧本转译**：`script_translator.py` 用标准库 `urllib` 调 DeepSeek `chat/completions`
  （OpenAI 兼容，模型 `deepseek-flash`），只输出 JSON 动作数组；无 Key / 网络失败 /
  解析失败时自动降级为 `main.parse_script_text()` 的规则解析，别名归一后照样可用。
- **录屏**：整个流程在同一个 Playwright context 内执行，单条录制，结束后 ffmpeg 转码 MP4。
- **可编辑化**：`enhance/config.js` 维护个人资料（头像/昵称/背景）与朋友圈数据，
  通过 `data-me-avatar` 等标记即时同步到页面所有位置。
- **打字节奏**：`main.py` 顶部常量区可调（速度、标点停顿、键盘按键保持时长等）。打字动画
  **永不出现打错回删**（已从代码中彻底移除），`[删除文字]` 动作不受影响。

## 六、拼音候选 / 苹果表情 构建与回滚

打字候选词库由 `enhance/pinyin_data.js`（`window.__WX_PINYIN`）驱动，为了更接近真机（Rime 主读音、
真实字频排序、curated 高频词、表情联想），链路如下：

```bat
py build_rime_dict.py            :: 可选：下载/解析 Rime 明月拼音词典 -> enhance/rime/rime_data.json（有本地缓存则跳过，断网回退 jieba）
py build_wusong_dict.py          :: 可选：下载/解析雾凇拼音(rime-ice)词典 -> enhance/rime-ice/wusong_data.json（真实语料词频，显著提升候选排序）
py build_pinyin_dict.py          :: 必选：合并 jieba + Rime + 雾凇 + curated 高频词，重建 enhance/pinyin_data.js
```

- **雾凇拼音**：用 `iDvel/rime-ice` 的真实语料词频重排候选（时间/非常/什么 等常用词居前）；只贡献词频/单字频，读音仍用 pypinyin，避免个别注音（如"这 zhei"）与标准音冲突。
- **打字按真词分段**：`main.py` 用雾凇词表做最长匹配分词，打字时一次上屏一个真实词（词长自然 1-2/3-5 变化），候选与上屏文字对得上，避免"候选和上屏对不上"的假感。
- **大词库快速注入**：`pinyin_data.js`（候选词库，体积大）用 `<script>` 内联注入让浏览器原生解析，比 `page.evaluate(大字符串)` 快很多（实测 10MB 词库从约 11s 降到约 2s），避免录屏/截图启动卡顿。
- **表情联想**：打字时命中 `enhance/emoji_map.js` 的词（如 开心->😄、好的->👍）会在候选条追加苹果 emoji；
  首槽显示「组合中拼音(蓝) + 词组」，与 iOS 微信键盘一致。
- **一键回滚**（改前已自动备份到 `enhance/_backup/<时间戳>/`）：

```bat
restore_candidate_backup.bat           :: 回滚到最近一次备份（双击即可）
py restore_candidate_backup.py --list  :: 列出所有备份
```

> 手动编辑 `enhance/emoji_map.json`（词 -> emoji）可扩充表情联想；苹果 emoji 图片已在
> `vue-WeChat/public/images/emoji/`，配套 `enhance/emoji_map.js` 直接手改即可
> （原 `fetch_apple_emoji.py` 下载脚本已移除）。

## 七、Rime WASM 引擎（雾凇）预编译缓存

录屏页的候选条有两条来源：默认走 `main.py` 注入的真实 Rime WASM 引擎（`vue-WeChat/public/engine/`），
引擎就绪后 `enhance/keyboard.js` 用 `__rimeEngine.process(拼音)` 取引擎真实候选（见 `main.py::_inject_rime_engine`）。
但 Rime 引擎每次录屏都是**全新浏览器 context**（无持久 profile，IndexedDB 不跨录屏保留），
而部署雾凇需要 `deploy()` 现场把词典编译成 `.bin`，冷部署要几十秒（本机约 16s，另一台实测 68~72s）。

为让录屏不再等部署，可**一次性预编译并缓存 build 产物**，之后每次录屏秒级就绪。
预编译产物已缓存在 `vue-WeChat/public/engine/rime-ice/build/`（当年用一次性脚本
`_capture_build.py` 生成，该脚本与 `_measure_rime.py` 已清理，无需再跑）。

原理与约定：

- **预编译产物**：一次性脚本把一次 `deploy()` 的 `/rime/build/*.bin` 静态打包到
  `vue-WeChat/public/engine/rime-ice/build/`（含约 59MB 的 `rime_ice.table.bin`、`rime_ice.prism.bin`、
  `rime_ice.reverse.bin`、`rime_ice.schema.yaml`、`default.yaml`）。
- **启动写回**：`main.py::_rime_bootstrap_js()` 先写源 yaml/dict 到 `/rime/`，再把这些预编译 `.bin`
  写回 `/rime/build/`（先写源、后写 build，让 build 的 mtime 更新），于是 `deploy()` 检测到产物已最新
  而**跳过重编译**，引擎就绪从几十秒降到约 6s。
- **本地加载**：引擎文件改为从 `/engine/` 本地加载（`worker_local.js`，`rime.js/%wasm/数据` 同源拉取），
  不依赖 jsdelivr CDN。
- **回退**：若 `vue-WeChat/public/engine/rime-ice/build/` 缺文件，`deploy()` 自动回退到冷编译（慢但可用）。
- **体积**：预编译产物约 60MB 本地静态资源，可接受（原本也要下载源词典）。

> 引擎文件来自 `@libreservice/my-rime`（AGPL-3.0-or-later）。
