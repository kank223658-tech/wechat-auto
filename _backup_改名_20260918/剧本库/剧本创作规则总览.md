# 剧本创作规则总览（完整版 · 2026-09-15）

> 本文是整个软件剧本创作规则的**唯一完整索引**，写新剧本 / 优化旧剧本前通读一遍。
> 每条规则都标注了权威出处，冲突时以「用户最新定标 > 主笔经验最新条目 > 校验器/机械门 > 生成器提示词」为准。
>
> 规则分四层：**① 体裁与结构 → ② 格式硬规则 → ③ 趣味与审美规则 → ④ 质量门（机械门 + 评委 AI）**。

---

## 0. 体裁定位（一切的根）

这不是聊天记录，是**教学引流短视频**（仿微信界面，30 秒~几分钟）。观众爽点两个：

1. **键盘字幕**：主角一边聊一边在键盘打出「技巧点评」（永远不发送、打完删掉）——导演解说，全片最精彩卖点；
2. **对方插话**：字幕停住那几秒，对方陆续发来消息，制造「我边讲解、对方边被拿捏」的博弈感。

权威出处：`创作模式_打字不发博弈字幕规范.md`（需求唯一权威口径）。

## 1. 结构骨架

### 1.1 标准段序（v3 固定骨架，共享硬规则第五节）
```
[历史会话] …10 个会话… [历史会话结束]
[打开聊天] 主线A → 开场钩子 → 「打字不发(字幕)→删除→我方短话术→对方连发」循环
           → 段尾 [对方后台发消息] 副线名|内容|t1 → [返回主页]
[打开聊天] 副线   → 短展开 → 段尾 [对方后台发消息] 主线名|内容|t2 → [返回主页]
[打开聊天] 主线A  → 中段朋友圈四连 → 她回头+立边界+邀约落地 → [返回主页]
[打开聊天] 粉丝-龙龙 → 单窗口钩子 + [发送图片] 图片=脱单教程 | 打开=否 + 扣6 → [返回主页]
[打开聊天] 主线A  → 收尾（确认邀约+边界感一句）→ [打字不发] 下课字幕 | 1.5 → [删除文字] -1（全片最后一行）
```

### 1.2 多会话交替（fail 级结构规则）
- **主线拆 2~3 段（各 25~45 行），禁止一人连聊上百行**；参考原文每段 25~29 行就切。
- 段间交替循环固定为 女生A→女生B→粉丝→女生A；**同人段间禁空切**（[返回主页] 后不得立刻重开同人）。
- **副线首条消息前必须有主线铺垫句衔接**（观众测试：副线硬切进来有划走风险）。
- ⚠️ 副线段长口径冲突已裁决：共享硬规则写「副线短段 12~24 行」，喜好档案 v2/v3 + 评委写「**女性副线段 ≥30 行**」（用户打回过「第二段太短」）——以 **≥30** 为准；「12~24」只适用于过渡性副线续段，女性副线独立成段一律 ≥30。
- 拆段停顿点选「我方消息刚发出、等她回」处；**拆段后每段开头必须补 [打开聊天]**（漏补=渲染执行失败）。
- 女性副线段 ≥30 行（用户打回过「第二段太短」）；粉丝窗口 8~15 行。

### 1.3 开场（v3/v5/v7 定标）
- **开场第一动作 = [发送表情] 表情包贴纸**（打招呼/松弛类短名，逐字取白名单），图片永不作第一动作；梗图退到开场白之后当图梗用（v7，2026-09-15）。
- 每篇「打字不发」开场最多 1 段，其余段用实质动作开场（[我方打字] 接她后台话头 / [查看图片] 点开对方发来的图）。
- **搭讪篇第一段必须完成朋友圈四连**：`[打开对方主页] 名 → [进入对方朋友圈] → [点开图片] 序号=1,1 | 停留=0.3 →（后续台词引用哪条动态，就再 [点开图片] 序号=N,1 | 停留=0.3；没引用也可再点一张美女照片，最多两张）→ [等待] 0.3 → [闪回聊天] 回到=名 | 闪黑=否`；时机=她第一次软化接招之后；**提了朋友圈就必须真的打开**（首选动作在前→[闪回聊天]→再用朋友圈细节接新话题；预告式「朋友圈借我参观下」紧随四连也放行；**提了却整段不打开=打回**，校验器已硬卡「台词提朋友圈必兑现」）；**点图口径（0915 定标）：每篇至少真点开一张美女照片；她的朋友圈有视频动态优先 `[播放视频]`（序号=第几个视频动态；判定看人设 `posts[].video` 是否非空），没有就只点照片；停留一律 0.3 不必太久。**⚠️ 这里的「视频」指**朋友圈动态里的视频**（`posts[].video`），**不是主页「视频号」（`preset.video`）**——本项目不做视频号，主页视频号区域一律留空。 ⚠️ 旧口径「三连+等待 1.2」「v5 四连」均被 v6（停留 0.3 + 引用图必点）取代。
- 「刚加上」类选题主线历史块首条必须是 `我通过了你的朋友验证请求，现在我们可以开始聊天了 | 时间`。

### 1.4 会话切换与后台消息（与打字不发同等硬性）
- 两次 `[打开聊天]` 之间必隔 `[返回主页]`，禁止聊天页直接跳聊天页。
- 对方在「我看别的会话」时来的消息 → `[对方后台发消息] 联系人 | 内容 | HH:MM`，写在**上一会话块尾、[返回主页] 之前**；**严禁出现在整份剧本第一次 [打开聊天] 之前**（开场白一律进历史块）。
- `[打开聊天]` 之后对方不许「凭空先发」旧消息。
- 从对方朋友圈/主页回原聊天用 `[闪回聊天] 回到=联系人`（一条到位，不插 [返回主页]）。

## 2. 格式硬规则

### 2.1 行格式与动作表
- 一行一条指令 `[动作名] 参数`，多段用 `|`；动作名只能逐字取自 `action_registry.py`（64 个动作），写错=静默丢行。
- 高频反面案例：`[对方发信息]`（对）、`[为我方打字]`（对）、漏右括号、旧写法 `[我方发表情]`（用 `[发送表情]`）。
- 停留秒数只许出现在三处：`[等待]` 独立行、`[打字不发]` 第 2 段纯数字、图片动作 `停留=`。**消息行尾写 `| 0.5` 会变成对方发出"0.5"气泡**。
- 每批任务书的「允许动作全集」之外的动作（闪回聊天、转账、语音等）除非明确允许，否则禁用。

### 2.2 [打字不发] 三段语义 + v4 回指定标
```
[打字不发] 字幕 | 0.5 | 插话1；插话2
[删除文字] -1
```
- 第 1 段=**给观众看的技巧字幕**，2~10 字短语标签（硬上限 14；引流 CTA/下课字幕可 ~16），「动作短语+空格+三五字补充」。金样：`接住不破防 / 顺着结论走 / 暗示见面 / 学以致用`。禁 15+ 字解释句。
- 第 2 段=纯数字停留；第 3 段=**她**发来的插话（多段用「；」）。
- **v4 定标（2026-09-15）：打字不发=回指式技巧标注**——放在我**上一条已发消息之后**，字幕讲解那句的技巧；她的插话是对那句的回应。字幕「预告我接下来要打什么」=用法错误，打回。金样：`[我方打字] 我觉得不好看` → `[打字不发] 调动女孩情绪 | 1.0 | 哦哦，好吧`。
- `[打字不发]` 第 1 段 ≠ 之后 `[我方打字]` 的话（同一句=抄错了）；打完必须 `[删除文字] -1`。
- 字幕禁写「她开口了/她接话了/她接招了」类承接描述（那是画面自己会演的，字幕只讲技巧）。
- **场景区分（重要）**：**视频转写**（对标复刻外部视频）忠实原片，预告式/回指式按原片写；**自己创作一律回指式**——预告式（`打字不发→删除→我方打字`）在创作稿里会被评委按 v4 定标打回。剧本库 README/共享硬规则里残留的「打字不发→删除→我方短话术→对方连发」循环写法是 v4 之前的旧骨架，已被回指定标取代。
- **禁连排独角戏**：连续两条打字不发中间只有删除=拖沓；并成一条或中间插对方插话/真实消息。
- `[删除文字] -1` 后到下一个我方动作之前，**禁止任何 [对方×] 行**（她的回应要么收进第 3 段插话，要么挪到该打字不发之前）；`[对方后台发消息]` 跨会话机制豁免。

### 2.3 插话（第 3 段）规则
- **视角铁律（校验器 3.12，fail）**：插话是**她**的消息——「我」=她、「你」=我。严禁四类：① 我方心理（「这是明着钓我」「吊着我」）② 我方策略（「见好就收」「看你怎么圆」「不如挑刺」「暴击/擦边/接住/反将」等策略词）③ 点评她刚发的东西（「就这光线 也敢发？」）④ 边界备注体（无人称+无语气词+像批注：「带钩的问题；先给证据再收」）。不复述她上一条（要有新信息）。
- **承接铁律（校验器 3.13，fail）**：插话锚点只有两个——**我上一条已发送的消息**、或她起的新话题；**输入框草稿她看不到，不能当锚点**。我删掉草稿后发的那句必须直接答她。三判据：回应型孤立句（「关你什么事」而上文没人管过她）/ 认责句空降（「这事怪我」而她没怪过我）/ 答非所问。
- **插话类型主次（v4）**：主型=回应式（对我已发消息的回应，占绝对多数）；次型=新话头式（她主动起话题/催促），少量点缀。
- 插话支持全部消息格式（写在插话段内，不写独立行）：`[对方表情] 短名`、`[对方图片] 短名`、`[对方链接] 标题|封面|来源`、`[对方emoji] 名`、`[对方转账] 金额|备注`（语音已禁用，不列）；文字内可内嵌 3D emoji。
- ★朋友圈台词真实性铁律（0915 用户点名）：聊对方朋友圈只能引用 peer_presets.json 该人物的真实 posts（文案/张数/日期）或主页签名——这些才会真的渲染上屏；禁止虚构画面（猫/机车/看展/甜品/多肉…），对不上就是穿帮。四连人名必须在人设库里存在。
- 转账收款链路（0915 已入动作表）：主流程 `[对方转账] 金额|备注 → [打开转账详情] → [接收转账] → [关闭转账详情]`；我方转账 `[转账] 接收人=名 | 金额=x | 备注=x`。适度使用，别泛滥。
- 开场插话无锚点变体：实时段我方一条未发时，她的插话只能顺她自己起的话题延伸（「丑话说前头；油一句我就删你」型），不能「验收」没发生的事。
- ⚠️ **已知口径冲突（预演型）**：生成器提示词（script_generator.py 502 行等）仍保留第三种来源「预演：我正打的这条若发出去她此刻会怎么回（真实话术要错开方向）」；但校验器 3.13 / 共享硬规则 / 评委 AI 已收紧为**只有两个锚点**（已发消息/新话题）。写稿安全做法=只用两锚点；确要用预演型，后续 `[我方打字]` 真实话术必须错开方向，且整段要人工过 3.13 的「答非所问」判据。

### 2.4 节奏定标（硬数字）
- **停留标尺只许 0.3 / 0.5 / 1.0 / 1.5**：常规带插话一律 0.5；0.3=短字幕快节奏；1.0=合并长字幕/博弈大窗口；1.5=下课字幕收尾。开场钩子图全屏停留不受此限（1.0~1.5）。
- **她说话前等待统一 0.2s（0914 晚定标 0.3→0.2）**：她每条 [对方发消息] 前（我方动作后、连发之间）显式写 `[等待] 0.2`；**我方连发不加**。⚠️ 口径冲突已裁决：主笔经验曾说「构建层自动补、剧本不用手写」，喜好档案 v6（2026-09-15）明确**稿面必须显式写出**——以显式写出为准。后台消息前若有我方行，同样补 `[等待] 0.2`。
- 额度：`[等待] 0.2` 全篇 6~10 处；`[手机状态栏] 无新消息` ×1；朋友圈四连 ×1；副线（女性）≥30 行；粉丝窗口 8~15 行。
- `[我方打字]` 单条 ≤20 字；要有连发 2~3 条的段落；交替率 ≤0.75。
- **复读禁令**：同一句话全篇不出现第 2 次；同一句式（「你倒X」「你倒是会X」）≤3；句首「行/成/行吧」≤2；同人台词同一开头 ≤2；同一语气词开头句式 ≤3。
- 开场形态多样：禁「每次进聊天都 [打字不发] 开场」。
- **她的主动性配比**：我方起话题/推进占大头；她连续起两个新话题=越权打回。

### 2.5 时间规则
- 历史块：按最后一条消息时间**从新到旧**排；同一人只一个 [会话]；同一会话只有**首末条**带「| HH:MM」且间隔 ≥5 分钟，**末条必带时间**；全剧本时间单调不倒流（历史块最晚时间早于实时段第一时间条）。
- 实时段时间条 ≤3 处（max_time_marks），只钉换天/隔很久节点。
- 邀约**版本全篇唯一**（时间+地点各一个说法）；多个邀约日期错开；邀约必须落地（对方明确答应）。
- 台词与动作匹配：说「照片」配 [点开图片]、说「视频」配 [播放视频]、提朋友圈必先有打开朋友圈动作。

## 3. 历史会话块（10 个 [会话]）

1. `[历史会话]` 开头 / `[历史会话结束]` 收尾；块顺序=首页列表顺序；**渲染器取前 10 位做主页联系人**（主页一屏最多 10 个，超 10=截断+警告判失败 → **实时段每个出场联系人必须已在历史块占位**）。
2. **★渲染铁律：微信列表页每行只显示该会话【最后一条】消息**（msg-item.vue 只渲染 msg[len-1]；图片显示"[图片]"、链接显示"[链接]"，图本身不渲染）→ **每个未打开会话只写 1 条**，钩子/擦边压在这一条里自带（两句式=前一句白写）。**唯一例外=粉丝会话**（写三段撑「我：」回复名额）。
3. **主线联系人尽量排历史块前 8 位**（软件已保证主角掉不出安全区，但前 8 位是保险写法；凑数闲聊放后面或删）。
4. **未打开会话的擦边 = 一句半截话、留想象空间（最终口径，三次纠正）**：「半夜睡不着」「一个人在家 有点冷」「刚洗完澡 头发还湿着」「我那里不舒服」「加班到腿软」「新买了一件小吊带」。**不接「你来…」式邀约尾巴**（说满了=堵死想象空间）；不加「别想歪」式解释。
5. **被打开（打开=是）的会话没这个限制**：擦边可多条、展开成一来一回（打开后全屏可见）。
6. **★至少 1 个会话必须有「我：」回复**（对方说→我回→对方再说），漏=机械门直接判失败；**最多 2 个会话带「我：」回复**（max_history_two_sided=2，超了=打回）。固定给粉丝会话写三段：粉丝发链接 + 我回一句 + 粉丝末条（带时间）。
7. 同一人连发 ≤2 条（历史块内任何人不许超 2 连发）；禁「在吗/哈哈/吃了吗/晚安」空话，每条都要有钩子。
8. **全部人名（含 7 个路人）逐字取自 people.json，禁止自造**（渲染器没头像）。
9. 粉丝会话必含：`[对方发链接] 聊天案例解析（必看） | 随机 | 恋爱技巧 | HH:MM`。
10. 其中 1 个会话放系统消息：`某名：我通过了你的朋友验证请求，现在我们可以开始聊天了 | HH:MM`（"刚加上"类必放主线）。
11. 历史块里的图/封面**不用准备素材**（列表页看不到）；想让列表行出现「[图片]」就把图放该会话最后一条。
12. 首页列表时间戳严格从新到旧；未读角标是「会话写多条」的唯一作用。

## 4. 三层分工（2026-09-14 用户定标：引流/有趣/历史块要区分开）

1. **①开局引流层（0~5 秒，拉停留）**：性感氛围图（刚洗完澡的对镜自拍/吊带裙/试衣间/马甲线，性感到位不露点）或擦边暗示话题（「刚洗完澡」「你觉得我这种身材好追吗」「你猜我现在穿什么」）。钩子两形态：**形态A 实时全屏**（`[对方发图片] 图片=x | 打开=是 | 停留=1.2`，放打开会话后第 2~3 个动作，先我方垫一拍）/ **形态B 历史块末条图片**（考古/回忆杀，全屏反而毁氛围）。
2. **②正文趣味层（智斗留人）**：博弈、图梗错位暴击、挑逗对攻、金句反差。**正文不堆性感**。
3. **③历史块层（列表页故事感）**：路人会话擦边半截话（见上）。
- 红线：擦边只做钩子不做内容，露骨描写禁止；抽掉擦边剧本仍成立。校验器 3.10 给提示。

## 5. 趣味与审美规则（评委打分的来源）

### 5.1 升温教学风格基准（总纲六条，一票定调）
判断成败先看**情绪曲线**，不看机灵程度：
1. **我方=直球进攻**：三步内上强度，夸必须具体到细节（黑白格裙/纱披肩飘起来），金句连发 ≥2，需求感敢亮，邀约干脆不绕安全牌（禁「市集+咖啡随便聊聊」保险单）。
2. **她每句回击带钩子水温+半度**（「哈哈哈哈怕了吗」「你话里有话哦 弟弟」「光吃饭看电影吗[脸红]」型）。**严禁评委式点评**（确实土/嘴挺贫/臭美/人还行 留着观察 = 废反应，打回）。
3. **她主动递钩子 ≥2 次**（「那晚上呢」型），但锚点必须是我方的撩。
4. **上头证据要展演不要转述**：副线/后台消息演出她破功（笑到失控/屏幕一亮就拿起）；闺蜜转述只算半证据。
5. **情绪曲线单调向上不回落**：开场→具体夸→金句→暧昧→[脸红]级→邀约，不回落纯搞笑层。
6. **直球真心时刻 ≥1 处**（「就想单方面表达一下我对姐姐的感觉」型），金句可以油但真诚收尾。
反面教材：《刚加的女生怎么聊》第一稿（防守型教学：自嘲化解/她全程看戏/安全牌邀约）。

### 5.2 梗密度（每篇 ≥4 梗 ≥3 梗型）
- **★图梗·错位暴击 = 第一梗型，每篇 ≥1 处**。四步：台词立预期 → 我方顺杆接 → 图错位 → 她笑骂收尾。金样A：她说喜欢高高瘦瘦的 →「正好认识一个特别符合的」→ 电线杆图 →「你拿电线杆糊弄我」。金样B：「jk大奈看吗」→ 奶龙穿JK。双向更好（对方也发梗图我方接梗反打）。角色池：奶龙/卡皮巴拉/悲伤蛙/汤姆猫/doge/奥特曼/黑人问号/旺仔/猫猫虫。
- 土味金句 ≥1（押韵对仗：「撒网是姐姐的本事 入网是我的荣幸」）；反差自嘲 ≥1（「我平时不这样的 平常很腼腆」）；网络热梗 2~4 处贴语境（栓Q/纯爱战士/已老实/那咋了…，同一梗词 ≤2，堆多=油）；教学自嘲/斗嘴/曲解梗都算。
- **道具呼应**：图梗优先复用开场图里的物件（她的开场图是粉色热水袋 → 图梗「独家止痛法」配橘猫摊在粉色热水袋上），画面呼应笑点更巧。
- 梗不能盖过教学主线。梗库：`对话乐趣梗库_2026热梗版.md`。

### 5.3 挑逗双向（趣味硬规则）
- 正文 ≥3 处挑逗类互动（图片梗/正话反说/抬杠式撩/曲解装傻）；**对方反撩 ≥2 次**，不能只有我方输出。
- 正话反说**落点必须与对方发的东西同主体**（校验器 3.11 fail）：照片→她本人/照片本身（「人比照片好看」），落到自己要另给逻辑桥；「显得我不够帅」类=低级错误。
- 开场评图模板病（校验器 3.14 fail）：**她先开口点题**（「我是不是胖了」）或图/状态摆出处境，我方第一句回应她的话或处境；严禁开场打分式评图（照片我看了/先说结论/三个问题/头像我已经鉴定）。

### 5.4 图片规则
- **图片描述=用户的找素材清单**，公式「主体+细节+画面形式」去空格 ≥10 字（校验器 3.5b 实时图硬卡；截图/长图类 ≥16 字且写清谁的截图+内容+形式；历史块预览图 ≥8 字提示）。正例：「夜晚城市江边跑步道 路灯下一双运动鞋特写 竖屏实拍」。
- **素材易得度三档（校验器 3.5c 硬卡）**：A 档首选=随手拍/相册翻/网搜就有（奶茶/外卖盒/猫/晚霞/衣架上的裙子/自拍/美甲/快递箱/票根）；B 档=单张手机自截聊天界面（单屏不加工）；C 档禁止=加工制作类（拼成/拼接/合成/裁出/红框）+ 造场景类（朋友圈/弹窗/转账/群聊/推销话术截图）。粉丝会话（引流图/脱单教程）例外。
- 描述末尾带获取线索（「竖屏实拍」「手机随手拍」「网图」）。
- **我方 [发送图片] 一律不写 打开=是**（校验器 3.4b 硬卡；全屏暴击交给 [对方发图片]）。
- **[查看图片] 永远只看对方发的图**；我方图永不查看、不进历史块（v5 图片归属定标）。
- **纯情绪反应用贴纸/emoji 不用图片**：[发送图片] 只留给剧情必需、有信息量的具体画面（校验器对卖萌类图给软提示）。

- 同一张图全篇只用一次；同一人连续发图 ≤2（锚点句+图并行，图放第二条）。
- **图片预绑定（0915）**：热梗图拷 `vue-WeChat/public/images/asset/` + 登记 `_gallery_meta.json`，剧本图片槽写 `/images/asset/xx.jpg` 全路径 → 配图清单直接「已配图」。

### 5.5 表情 / emoji
- 贴纸短名逐字取白名单（`py -c "import script_generator as G; print(G._asset_block())"`）。
- 内嵌 `[表情名]` 只认 `wxemoji3d_map.js` 的 372 个键（3.4c 硬卡；[偷笑]/[捂嘴笑] **不在库里**，参考样本跳门禁所以能留，别学）。
- **emoji 多用微信高频款（v6）**：狗头保命/呲牙/捂脸/笑哭/大笑/害羞/坏笑/Emm/白眼惊/握手/OK/赞/偷看/举手；同名 ≤2、总数 ≤10、≥6 种；冷门款只点缀；我方和她都要有。
- 表情总数额度 ≤10、同一表情 ≤2；开场插话别堆。

### 5.6 三线规格（各线互不重叠）
- **每篇至少 2 个女生，话题必须不同**：主线+副线的教学点、入口方式、聊天内容不得重叠（例：主线=街搭冷回复升温；副线=女生深夜主动找你=情绪窗口怎么接）。

## 8. 语义自检清单（机检兜不住的，写完逐条过）

1. **字幕因果时序**：字幕出现在触发它的信号**之后**（信号在前、点题在后）。
2. **改台词必查下游引用**：改/删任何一句，回头搜这句被谁引用过（「你说的XX」/她的复述/插话衔接）一起改。
3. **删段查悬空**：铺垫和结论要么一起在要么一起删。
4. **人设隔离**：主线/副线禁 博主/学员/教学/关注/扣6/秘籍；台词禁行话（主线/带线/闪着/复盘）——「不看教学背景能懂吗」逐句过。
5. **改写/重排后全文重读**：查重复段、重复教学、因果连续。
6. **插话里不用「他」指我**；她的话不能和自己前一条打架。
7. **主页会话上限 10**：实时段联系人必须都在历史块占位。
8. **方法论只进字幕不进聊天正文**。
9. **相邻字幕不重复**：两条字幕不能教同一个动作（两条都是「别追问」），每条推进一个新要点。
10. **叙事闭环**：历史块最后一条 = 主线打开时的情绪起点；副线切换时必须先给出该副线的状态证据（一条消息/一张图），再上字幕点评。
11. **开场点题核对**：她先开口说选题（「我是不是胖了」），或她的图/状态把处境摆出来；我方第一句回应她的话或她的处境（3.14 抓不到的变体靠人工）。

## 11. 元教训（流程层，写稿同样适用）

- **批量修改禁用 Edit 连环调用**（同轮并行 15 个只落 2 个）——用 python replace + 当场 grep 验证落盘。
- 「写手又犯」类问题先 grep 校验器确认规则真的存在，再决定补救层级（提示词 vs 确定性检查）；教训记错层=坑必然复发。
- 子代理 10 并发会撞 429：写作波保持并发，审判波可降为主会话亲审+机械门兜底。
- 单稿单写手（剧情/格式/节奏三难度不分件）；批量并行只加在「跨剧本」维度。
- 规则宁可窄而准——误报会让人不再信机械门。
