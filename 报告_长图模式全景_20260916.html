一、它是什么

复刻抖音「直男许诺」类聊天记录长图视频的全自动生产线：

JSON 对话 / 上传整图
→
正宗微信长图（真微信样式 + DOM 坐标真值）
→
动态镜头（逐句下移 / 换人平移 / 拉近拉远）
+
BGM 强拍卡点
→
横屏成片 MP4

对标结论（逐帧实测《当女生下定决心要跟你分开该怎么回复》，105.8s / 30fps / 横屏）： 滚动落点与 BGM 强拍逐一重合（4.7 / 8.45 / 10.32 …秒），不是匀速也不是定时器；顶栏属于长图的一部分，会随滚动移出画面。

四、两种出片模式

① wx · 微信仿真（默认，推荐）

JSON 对话 → wx_export.py 用 playwright 打开 8080 的仿真微信页，按 chat_exact.css 排版整段对话，full_page 截图出正宗微信样式长图，同时用 getBoundingClientRect 量出每条消息的气泡/头像/点评行矩形，写成 manifest.json。

渲染端读清单做零探测纯算术取景。坐标真值包含：气泡矩形、头像矩形、点评行底 y、点评文字横向范围 tx0/tx1、结尾 CTA 的 Range 实测矩形。

前提：8080 前端必须在跑（_port_open 检查，未运行直接报「前端 8080 未运行」）。

② longimg · 上传整图

用户自己拼好的长图 → 像素探测：bands_from_image 用「暗色文字」判据切内容带（dark = g < 100，覆盖率阈值 0.015，合并 90px），中位数定文字质心 x、2%/98% 分位定水平范围；side_by_color 用绿泡颜色判左右（绿像素占比 ≥1.5% 才信颜色，否则退回中点判定）。

再把头像死区剔掉（R 侧 xhi 收到 0.905W、L 侧 xlo 抬到 0.095W），避免头像照片里的暗像素污染取景范围。

精度弱于 wx 线；不上片头逐块滑入；也支持「用最近导出的微信长图」直接复用。

六、镜头算法（现行 v3，坐标真值驱动）

规则实现
逐句下移（句数定标）取景集 = 第 k..i 句，同侧连发第 1 句框 1 句、第 2 句拉远到 2 句同框、第 3 句 3 句，之后滑动窗口始终最近 3 句（MAX_N=3，run_start 标记同侧连发起点）
换人换边发言人变侧立刻横移到那一侧，句数从 1 重数
头像永远完整锚定头像外缘 + OUT_PAD=0.04W 外留白；装不下自动降倍率。清单无头像真值时按微信皮肤常量反推（62.6px 头像 / 18.3px 间距）
底边收紧窗口底边钉在当前内容底（泡 or 点评行下缘）；下一条紧贴时 bot_m=0（一个像素不露），否则留 BREATH*avg_h 呼吸。多余高度全给上方已读内容
长蓝字取景点评文字横向范围（tx0/tx1）并入宽度需求 req_w：短泡配长蓝字时自动拉远装下，镜头上移，底边收紧兜住
缩放呼吸缩放用 zglide = min(glide*1.8, 下一步间隔-0.2)，比位移更缓 —— 移动干脆、缩放像呼吸拖尾
结尾全景最后一句：前一句 + 当前句 + 点评 + CTA 完整同框，横向居中于内容整体
开场滑现opening_pan：起点倍率 = 落定 ×1.22 并放大，首句泡被画面缘切掉 30%（L 侧切左缘 → 右→左滑；R 侧反之），匀速推到落定，约 0.7s 泡滑完整。第一句话「慢慢出现」而不是开局就在。第一滑 glide 拉到 ≥0.9s
倍率边界Z_MAX=4.2；最小倍率受滑杆 zoom 下限约束（默认 1.0）；高度下限 1920/9、宽度下限 1920/6 等比保护
pan 模式side=跟人走（推荐）；center=不横移只缩放（wx 线固定 side）

七、鼓点与时间轴

  • 强拍检测：scipy.signal.spectrogram（nfft 1024 / hop 512）→ log1p 压缩 → 正半波谱通量 → 5 点平滑 → find_peaks(distance=min_gap)；掐掉前 0.5s 不稳点。
  • 落点规划：plan_step_beats 从强拍池里取 n_steps 个；相邻间隔超 max_step 等分补拍（音乐空拍也继续走）；鼓点不够按中位步距续补；兜底 1.9s 均铺（对标实测平均步距≈1.88s）。
  • 片头：前 intro.blocks 条消息按强拍从侧边滑入（ease_out_cubic + 55% 屏宽位移），半秒滑完。
  • 开场静止：动态镜头默认撑 2 拍，第一步落在第 3 拍。
  • 收尾：total = min(bgm_len, 最后落点 + tail_hold)；落点若越过音乐尾部，整体前移保住淡出。BGM 不够长自动循环补齐，结尾按 fade_out 线性淡出。
  • 实测日志样例：[鼓点] 强拍 64 个，前 8 个 [1.63, 2.82, 4.7, 6.58, 8.45, 10.32, 12.2, 14.08] —— 与对标视频落点完全一致。
