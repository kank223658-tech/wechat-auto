# 剧本参考改编流水线

一条主线：**好作品 = 可歪钩子 + 全程智斗暧昧 + 真实感 + 结构零硬伤。**

权威规则与底稿：
- 作业书与权威口径：`.workbuddy/skills/创作模式全流程/SKILL.md`、
  `创作模式_打字不发博弈字幕规范.md`
- 合格底稿池**只有** create.db `ref_scripts` 表里 7 篇「直男许诺」full 金样
  （8241/6041/3234/3876/2890/1324/1450 赞）。
  `剧本库` 根目录的生成稿和其他自动沉淀稿**禁止当底稿**。
- 本流程由当前模型直接写，**不调用内置 DeepSeek**。

## 阶段 1 — 台账先行（约束前置，释放发挥）

1. 用户给选题后，先从 7 篇金样中判定形态最接近的底稿；同形态=换皮。
2. 在剧本将存放的目录（`剧本库/_inprogress/<选题>_参考改编/`）复制台账模板：
   `.workbuddy/skills/创作模式全流程/状态台账模板.md` → `01_改编稿.台账.md`。
3. 先填再写：人物锁（people.json 真名）、关系起点、关系阶段（带真实 HH:MM）、
   每个承诺的「首提词 → 兑付词」、信息边界。
4. 台账可先给用户过目；用户已授权独立完成时直接进入阶段 2。

## 阶段 2 — 参考改编

- 保留底稿骨架与约 85% 对话：双线/三线结构、图梗、金句、推拉原样不动。
- 只改 4~6 处：开场可歪钩子、中后段 1 处反将/推拉、粉丝线教学点对齐、
  结尾字幕对题；字幕按「技巧拆解（动作+目的）／读她（看似X实则Y）／情绪／钩子」
  四目的写，6~16 字，禁「故意曲解」类空标签。
- **每个新写的句子必须从她刚说的具体内容里长出来**——禁止为模仿短句质感写
  漂浮句（如无来由的「急了？」）。
- 历史块按规范重建：每会话有来有回、我方前缀「我：」、10 个会话、真名。

## 阶段 3 — 完稿后一次性双门体检

**先完整写完，再一次性跑门。绝不进入「写两句→报错→改」的纠错环。**

```powershell
# 系统 Python 3.12（py），中文输出需设 UTF-8
[Console]::OutputEncoding=[System.Text.Encoding]::UTF8; $env:PYTHONIOENCODING="utf-8"
py _check_script_quality.py "剧本库/_inprogress/<目录>/01_改编稿.txt"
py _check_script_logic.py "剧本库/_inprogress/<目录>/01_改编稿.txt" --require-ledger
```

- 机械门管格式，逻辑门管状态（L1~L9），两门都绿才进阶段 4。
- 修复顺序：先处理 [问题] 级；[提示] 级只当观感，不刷绿。

## 阶段 4 — 敌对语义审稿（人味关，不用正则）

切换为「专门找茬的场记」立场，只许引用行号，逐条审：

1. **可歪浓度**：开场递进、宾语空着、我方零漂亮话、落点极日常。
2. **全程不断线**：中后段没退化成关心/伺候；试探-反将-反推拉-反转真的演出来。
3. **她的主动性证据**：每主线会话 ≥1 处递球型插话、≥2 轮真拒绝；
   逐条插话前加「她说」复读，不通顺就改。
4. **真实感与画面层**：细节锚在她的具体信息上；低信息句（嗯/哼/哦哦）保留；
   每句台词问「屏幕上放得出来吗」。
5. 我方保留 1~2 处失守瞬间（约占字幕 5%），不做零破绽的机器。

## 铁的边界

- **机械检查只抓命题型错误**（名字、时间、承诺、信息差、指代落点），
  审美型判断（好笑吗、狠吗、节奏妙吗）绝不正则化。
- **不为刷绿指标删戏、拆句、砍她的合理反应。** 数字是观测值不是验收线。
- 约束用「禁止」不用「规定」：禁区外全部自由；关键锚点用户锁，框架内模型自由。

## 交付

留在 `剧本库/_inprogress/`，一次交付：
- `01_改编稿.txt` + `01_改编稿.台账.md` + 《修改对照说明》（原文/改后/为什么）
- 标注渲染前需补的图片素材（库内贴纸与 emoji 须已验证可解析）。
用户确认后再归档 `剧本库/成品/` 并沉淀入库；不自行移动或提交。
