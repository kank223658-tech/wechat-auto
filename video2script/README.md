# video2script — 对标博主视频 → 剧本草稿

把对标博主的微信聊天录屏自动拆成剧本 txt 草稿，**确认代替手打**（目标 30 分钟手打 → 5 分钟确认）。

## 新电脑启动（两步）

1. 电脑装好 Python 3.10+（官网下载，安装时勾选 **Add Python to PATH**）
2. 双击 **`1-安装依赖.bat`**（需联网，装到本文件夹的 `.venv`，不污染系统）

## 日常使用

- 把博主视频（mp4 等）放进 **`input_videos\`**，双击 **`2-视频转脚本.bat`**
- 或者：直接把单个视频**拖到** `2-视频转脚本.bat` 图标上

输出在 `output\<视频名>\`：

| 文件 | 说明 |
|---|---|
| `<视频名>.draft.txt` | 剧本草稿。`[?]` 开头的行 = 机器没把握，需要你确认/改 |
| `report.md` | 不确定点清单（人工只看这个） |
| `frames/` | 关键帧截图，报告里提到的画面都在这里 |

草稿确认完 → 复制进 `剧本库\_inprogress\对标拆解\` 当对标素材，后续喂给风格 skill。

## 校准模式（换新来源/新机型的录屏先跑一次）

```
.venv\Scripts\python.exe video2script.py <视频> --probe
```

会输出页面分类统计 + 抽样帧。如果分类错得多（聊天页认成列表页等），
把抽样帧情况发我，我调 `classify_page()` 里的版式签名参数。

## 文件结构

```
video2script\
├── 1-安装依赖.bat      新电脑跑一次
├── 2-视频转脚本.bat    日常入口（支持拖拽）
├── video2script.py     管线主体
├── requirements.txt
├── input_videos\       ← 博主视频放这里
└── output\             ← 草稿+报告输出
```

## v1 已知边界（诚实声明）

- 页面分类是启发式签名，第一次跑真视频需要 `--probe` 校准一轮
- 朋友圈页 / 图片查看器只标记位置不翻译内容（报告里提示人工补）
- 表情匹配覆盖 wxemoji3d + sticker 图库；都没匹配上会落到 `[?]` 行
- 打字不发 / 插话靠「输入框增长→清空且无新气泡」签名，快剪视频可能漏，
  漏了会体现在草稿缺 `[打字不发]` 行——确认时对着画面补
